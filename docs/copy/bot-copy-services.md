> מסמך מקור לשני דברים: (1) המחרוזות בשיחה של Microsoft To Do ו-SharePoint (`lib/copy/bot-services.ts`, בדיקה מוודאת שכל id מתועד כאן), ו-(2) הטקסט של שורת האייקונים ב"חיבורים" באזור האישי (`lib/connections/services.ts`).

## 1. וואטסאפ

### `s.todo.consent`
**מתי:** חיבור Microsoft 365 בלי `Tasks.ReadWrite` (חובר לפני 23.10.2026, או שהארגון לא אישר) ומבקשים להציג או להוסיף משימה. הכלים `todo_*` מחזירים את הטקסט, והמודל מעביר אותו כלשונו.
**משתנים:** `{link}` (חד-פעמי, 30 דקות)
```
כדי שאוכל לעבוד עם Microsoft To Do צריך לחבר מחדש את Microsoft 365 ולאשר את ההרשאה למשימות:
{link}
בארגון שבו מנהל ה-IT מאשר אפליקציות, ייתכן שתופיע בקשה לאישור מנהל.
הקישור עובד ל-30 הדקות הקרובות.
```

### `s.todo.consent_no_link`
**מתי:** כמו `s.todo.consent`, כשאין לכלי בונה קישורים (גיבוי).
```
כדי שאוכל לעבוד עם Microsoft To Do צריך לחבר מחדש את Microsoft 365 ולאשר את ההרשאה למשימות. אפשר לכתוב "לחבר את Microsoft 365" ואשלח קישור.
```

### `s.todo.created`
**מתי:** `todo_create_task` הוסיף משימה לרשימה הראשית (פעולה פנימית כמו תזכורת, בלי כפתור אישור). המודל עונה בנוסח הזה.
**משתנים:** `{title}`, שם הרשימה, תאריך יעד (24.10) אם יש

## 2. אתר: שורת השירותים ב"חיבורים" (`/account`)

מתחת לכל חשבון מחובר: אייקון לכל שירות. ריחוף, פוקוס במקלדת או נגיעה מציגים בועה קטנה. השורה הראשונה היא גם השם הנגיש של האייקון (`aria-label`), והשנייה (ושורת הפעולה, כשיש) היא התיאור (`aria-describedby`).

**שורת הפעולה** (רק ב"צריך אישור נוסף", האייקון הוא קישור): Google - `לחיצה פותחת את האישור ב-Google`; Microsoft - `לחיצה פותחת חיבור מחדש ב-Microsoft. בארגון ייתכן שיידרש אישור מנהל`. בנגיעה (טלפון) הנגיעה הראשונה מציגה את הבועה והשנייה פותחת את האישור.

**מתחת לשורה,** כשיש שירות שמחכה לאישור: `שירות אחד מחכה לאישור נוסף` / `{n} שירותים מחכים לאישור נוסף`.

**סטטוסים:** `מחובר` · `צריך אישור נוסף` (לחיצה פותחת את האישור) · `לא זמין`.

| שירות | שורה ראשונה | מחובר | צריך אישור נוסף | לא זמין / חלקי |
|---|---|---|---|---|
| Gmail | `Gmail - מחובר` | קריאה, חיפוש וסיכום של מיילים, ושליחה אחרי אישור | השליחה פעילה. קריאה וסיכום של מיילים מחכים לאישור | (מחובר) שליחת מיילים אחרי אישור |
| יומן Google | `יומן Google - מחובר` | הצגה, קביעה והזזה של פגישות, כולל Google Meet | (מה השירות עושה) | - |
| Google Tasks | `Google Tasks - צריך אישור נוסף` | הצגה והוספה של משימות | (מה השירות עושה) | - |
| Google Drive | `Google Drive - מחובר` | חיפוש וקריאה בכל הקבצים, ושמירת מסמכים | כרגע רק קבצים שנוצרו דרכי. חיפוש בכל ה-Drive מחכה לאישור | (מחובר) קבצים שנוצרו או נפתחו דרכי, ושמירת מסמכים |
| Google Docs / Sheets / Slides | `Google Docs - מחובר` | קריאה של מסמכים / גיליונות / מצגות קיימים | (מה השירות עושה) | פתוח כרגע רק למשתמשים הראשונים, והמקומות התמלאו · כבוי כרגע. שאר השירותים ממשיכים לעבוד |
| Outlook | `Outlook - מחובר` | קריאה, חיפוש וסיכום של מיילים, ושליחה אחרי אישור | (מה השירות עושה) | - |
| יומן Outlook | `יומן Outlook - מחובר` | הצגה, קביעה והזזה של פגישות, כולל Teams | (כמו Outlook) | - |
| OneDrive | `OneDrive - מחובר` | חיפוש וקריאה של קבצים | (כמו Outlook) | - |
| SharePoint | `SharePoint - צריך אישור נוסף` | חיפוש באתרים ובספריות המסמכים של הארגון | (כמו Outlook) | - |
| Microsoft To Do | `Microsoft To Do - מחובר` | הצגה והוספה של משימות | (כמו Outlook) | - |
| קבצי Word, Excel ו-PowerPoint | `קבצי Word, Excel ו-PowerPoint - מחובר` | קריאה של מסמכים, גיליונות ומצגות מ-OneDrive ו-SharePoint | (כמו Outlook) | - |

- "כולל Google Meet" / "כולל Teams" מתייחס לקישורי הפגישה באירועים (נבנה במקביל, באותם הרשאות יומן).
- כשקריאת Gmail או Drive כבויה או שהתקרה מלאה, Gmail ו-Drive נשארים "מחובר" עם מה שעובד, ו-Docs / Sheets / Slides "לא זמין".
- כותרת הרשימה לקורא מסך: `שירותים ב-Google` / `שירותים ב-Microsoft 365`.
