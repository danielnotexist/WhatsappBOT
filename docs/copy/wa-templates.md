# תבניות Meta (Utility) — הודעות מחוץ לחלון 24 השעות

> הודעה חופשית מותרת רק בתוך 24 שעות מההודעה האחרונה של המשתמש (PLAN §5). כל הודעה יזומה שלנו — סיכום בוקר, תזכורת, תשלום, חיבור שפג — חייבת להיות תבנית מאושרת מראש. כל התבניות כאן בקטגוריה **UTILITY** (לא Marketing: אין תוכן שיווקי, רק עדכונים על חשבון/שירות שהמשתמש ביקש), שפה `he`, ומשתנים ממוספרים `{{1}}`, `{{2}}`…
> המדיניות: שם תבנית באותיות קטנות וקו תחתון; עד 1,024 תווים בגוף; משתנים לא צמודים זה לזה ולא בתחילת/סוף הגוף; **ערך של משתנה בשורה אחת בלבד** — בלי ירידת שורה, טאב או יותר מ-4 רווחים רצופים (אחרת שגיאה 132018 בשליחה); חובה `example` לכל משתנה; שינוי טקסט = גרסה חדשה לאישור (עד 24 שעות, בדרך כלל דקות). מספר הטלפון/ה-WABA ב-`WA_PHONE_NUMBER_ID`; רישום דרך `POST /{WABA_ID}/message_templates`.
> שם המוצר — **עלזה** — כבר כתוב בטקסט הקבוע של התבניות (לא משתנה). `APP_DOMAIN` עדיין placeholder עד רכישת הדומיין.

## טבלת התבניות

| שם | מתי נשלחת | משתנים | כפתור |
|---|---|---|---|
| `morning_summary` | pg_cron בשעת הבוקר של המשתמש, כשאין חלון פתוח | 1 יום, 2 פגישות, 3 מיילים, 4 תזכורות | Quick reply "לנסח תשובה" |
| `reminder` | כשהגיע זמן תזכורת | 1 טקסט התזכורת, 2 זמן מקורי | Quick reply "בוצע" / "עוד שעה" |
| `trial_ended_payment` | ההודעה ה-10 בניסיון הסתיימה, המשתמש לא ענה מאז | 1 שם | URL לתשלום (סיומת דינמית) |
| `payment_success` | אחרי VERIFY מוצלח של HYP | 1 מסלול, 2 סכום, 3 תאריך חיוב הבא | — |
| `payment_failed` | חיוב חודשי נכשל (יום 1/3/5) | 1 סכום, 2 יום ניסיון הבא | URL לעדכון כרטיס |
| `reconnect_needed` | refresh token נכשל מחוץ לחלון | 1 ספק (Microsoft 365 / Google) | URL חיבור מחדש (30 דק׳) |
| `plan_limit_reached` | 750 הודעות נוצלו בבסיסי | 1 תאריך חידוש | URL שדרוג |

לכל תבנית: הטקסט בעברית, ואז ה-JSON המדויק ל-Create Template API. ב-JSON של ה-URL button הכתובת מסתיימת ב-`{{1}}` — Meta מאשר רק סיומת דינמית של URL קבוע (הדומיין נקבע ברישום).

## 1. `morning_summary`

```
בוקר טוב. {{1}}

פגישות היום:
{{2}}

מיילים שמחכים לתשובה:
{{3}}

תזכורות:
{{4}}

כדי להמשיך — אפשר פשוט לענות כאן.
```
> סעיף ריק מקבל "—" (Meta לא מאפשר משתנה ריק). **משתנה לא יכול להכיל ירידת שורה** (וגם לא טאב או יותר מ-4 רווחים רצופים) — Meta דוחה את השליחה בשגיאה 132018. לכן כל רשימה נשלחת בשורה אחת, פריטים מופרדים ב-"•" ושני רווחים: `• 09:00 דיון  • 12:00 פגישה` (`templateParam()` ב-`lib/wa/templates.ts`). ירידות השורה בגוף התבנית עצמו (הטקסט הקבוע) מותרות. הכפתור "לנסח תשובה" פותח חלון ומפעיל את `act.mail.draft_reply` על המייל הראשון ברשימה.

```json
{
  "name": "morning_summary",
  "language": "he",
  "category": "UTILITY",
  "components": [
    {
      "type": "BODY",
      "text": "בוקר טוב. {{1}}\n\nפגישות היום:\n{{2}}\n\nמיילים שמחכים לתשובה:\n{{3}}\n\nתזכורות:\n{{4}}\n\nכדי להמשיך — אפשר פשוט לענות כאן.",
      "example": {
        "body_text": [[
          "יום ג׳ 22.10",
          "• 10:00 פגישה עם כהן (משרד)\n• 14:30 שיחה עם רו״ח ברק",
          "• רונית לוי — הצעת מחיר לפרויקט\n• עו״ד שפירא — הסכם פשרה",
          "• 16:00 להתקשר לבנק"
        ]]
      }
    },
    {
      "type": "BUTTONS",
      "buttons": [
        { "type": "QUICK_REPLY", "text": "לנסח תשובה" },
        { "type": "QUICK_REPLY", "text": "מה יש מחר?" }
      ]
    }
  ]
}
```

## שליחה (Send API) — מבנה אחיד

`POST https://graph.facebook.com/v21.0/{WA_PHONE_NUMBER_ID}/messages`

```json
{
  "messaging_product": "whatsapp",
  "to": "972501234567",
  "type": "template",
  "template": {
    "name": "reminder",
    "language": { "code": "he" },
    "components": [
      { "type": "body", "parameters": [
        { "type": "text", "text": "להתקשר לבנק לגבי ההלוואה" },
        { "type": "text", "text": "יום ב׳ 20.10, 18:40" }
      ]}
    ]
  }
}
```
כפתור URL עם סיומת דינמית: `{"type":"button","sub_type":"url","index":"0","parameters":[{"type":"text","text":"u_7f3a9c"}]}`.
Quick reply לא דורש פרמטרים; הלחיצה חוזרת ב-webhook כ-`button` עם ה-`text` של הכפתור ו-`payload` (אם הוגדר).

## רישום (Create Template API)

`POST https://graph.facebook.com/v21.0/{WABA_ID}/message_templates` עם ה-JSON של כל תבנית למעלה, header `Authorization: Bearer {WA_ACCESS_TOKEN}`. התשובה מחזירה `id` ו-`status` (`PENDING` → `APPROVED`/`REJECTED`; עדכון סטטוס מגיע גם ב-webhook `message_template_status_update`). הסטטוס נשמר בטבלת `wa_templates`.

## מה דניאל צריך לעשות ידנית
1. להחליף `APP_DOMAIN` בדומיין הסופי בכל ה-JSON לפני הרישום (השם עלזה כבר בפנים).
2. לרשום את 7 התבניות (דרך הסקריפט שייכתב ב-`lib/wa/templates.ts` או ידנית ב-WhatsApp Manager → Message templates).
3. אם תבנית נדחית בגלל "variable at start/end" — להוסיף מילה קבועה לפני/אחרי המשתנה ולשלוח שוב.
