# טקסטים — התראות יזומות ואזהרות פישינג (מסלול פרו)

> משלים את `bot-copy.md` ואת `bot-copy-m5.md` (אותן מוסכמות: פנייה ניטרלית, עלזה בלשון נקבה, בלי "שלח/י"). מיושם ב-`lib/copy/bot-proactive.ts` (`pcopy`), ומבחן מוודא שכל מזהה מתועד כאן.
> ההחלטה של דניאל (23.10.2026): בתוך סיכום הבוקר, ובנוסף עד 2 התראות דחופות ביום למשתמש. רק בפרו (`entitlements.proactive`, נבדק בשרת). הקוד: `lib/proactive`.
> כל שם, כתובת ונושא שמגיעים מתיבת המייל או מהיומן עוברים `oneLineUntrusted` (שורה אחת, מנוקה, מקוצרת) לפני שהם נכנסים לטקסט.

## מתי נשלח מה

| מה | מתי | ערוץ |
|---|---|---|
| "דברים שכדאי לא לפספס" | בסיכום הבוקר, א׳–ה׳, בשעה שהמשתמש בחר | בתוך חלון 24 השעות: טקסט + רשימת פעולות. מחוץ לחלון: תבנית `morning_summary` — שורות המייל בסעיף המיילים, שורות היומן בסעיף הפגישות, והכפתור [לנסח תשובה] נושא את המייל הראשון (`al:reply:<id>`) |
| התראה דחופה | עד 2 ביום, 08:00–20:00 (שעון המשתמש, ברירת מחדל Asia/Jerusalem), לא בשבת ובחג ולא בערב שבת/חג מ-14:00 | בתוך חלון 24 השעות: טקסט עם כפתורים. מחוץ לחלון: התבנית `proactive_alert` (`alert.template.*`). מעל 2 ביום, או כששליחת התבנית נכשלה — נרשמת ונכנסת לסיכום הבוקר הבא |
| אזהרת פישינג | בסיכום הבוקר (מיילים מ-3 הימים האחרונים), וכשעלזה קוראת או מסכמת מייל לבקשת המשתמש | קריאה בלבד. "לסמן כחשוד" רק ב-Microsoft 365 עם Mail.ReadWrite |

## 1. הסעיף בסיכום הבוקר

### `alert.section_title`
**מתי:** כותרת הסעיף, ראשון אחרי "בוקר טוב" (מוצג רק כשיש בו שורות).
```
דברים שכדאי לא לפספס
```

### `alert.item.awaiting`
**מתי:** מייל מאדם (לא דיוור, לא no-reply, בלי List-Unsubscribe / Auto-Submitted / Precedence) שמחכה לתשובה 2 ימי עסקים ומעלה (א׳–ה׳, בלי חגים). עד 3.
**משתנים:** `{who}`, `{subject}`, `{days}`
**כפתורים:** `[לנסח תשובה]` (`al:reply:<id>`), `[להזכיר מחר]` (`al:remind:<id>`)
```
• {who} מחכה לתשובה {days} ימי עסקים — {subject}
```

### `alert.item.deadline`
**מתי:** מועד שנכתב במייל מ-14 הימים האחרונים ("עד יום ה׳", "עד ה-30.10", "עד סוף השבוע", "by Friday") ונופל מהיום ועד שבוע קדימה. עד 3.
**משתנים:** `{when}` ("היום" / "מחר" / "ביום ה׳ 22.10"), `{subject}`, `{who}`
**כפתורים:** `[לנסח תשובה]` (אם עוד לא נענה), `[תזכורת למועד]` (`al:dl:<id>` — יום לפני ב-9:00)
```
• מועד {when}: {subject} ({who})
```

### `alert.item.conflict`
**מתי:** שתי פגישות חופפות היום (גם בין יומן Microsoft ליומן Google). אותה פגישה בשני היומנים אינה התנגשות. עד 2.
**משתנים:** `{a}`, `{b}` ("09:00 דיון בבית משפט")
**כפתור:** `[לטפל בהתנגשות]` (`al:conf:<id>`)
```
• התנגשות ביומן: {a} חופפת ל-{b}
```

### `alert.item.back_to_back`
**מתי:** פגישה מתחילה עד 10 דקות אחרי שהקודמת נגמרת, בשני מקומות פיזיים שונים (לא פגישות מקוונות).
```
• פגישות צמודות במקומות שונים: {a}, ומיד אחריה {b}
```

### `alert.item.external`
**מתי:** פגישה בהמשך היום עם משתתף מחוץ לעסק (דומיין אחר; בחשבון Gmail/Outlook פרטי — כל כתובת אחרת; לא חדרי ישיבות). עד 2.
**משתנים:** `{meeting}` ("13:00 שיחה עם משפחת אברהם"), `{who}` ("יוסי אברהם" / "יוסי אברהם ועוד 2")
**כפתור:** `[תדריך לפגישה]` (`al:brief:<id>`)
```
• {meeting} עם {who}. אפשר לבקש תדריך קצר לפני
```

### `alert.item.urgent_mail`
**מתי:** התראה דחופה על מייל שלא נשלחה (החלון היה סגור או ששתי ההתראות של היום נוצלו) — מוצגת כאן פעם אחת.
```
• מייל דחוף מ-{who} — {subject}
```

### `alert.item.phishing`
**מתי:** מייל מ-3 הימים האחרונים שנראה כמו פישינג או הונאת BEC. עד 2. כפתור `[לסמן כחשוד]` רק כשאפשר.
**משתנים:** `{who}`, `{subject}`, `{reasons}` (ראו §4)
```
• ⚠️ שימו לב: {reasons} — {who}, {subject}
```

### `alert.actions.body`
**מתי:** הודעת רשימה מיד אחרי הסיכום (בתוך החלון בלבד), שורה לכל פעולה (עד 10). כותרת השורה היא שם הפעולה (עד 24 תווים); שורה שנייה של אותה פעולה מקבלת את המילה הראשונה של הפריט ("לנסח תשובה · רונית"), והתיאור (עד 72 תווים) הוא "{who} — {subject}" או הפגישה.
```
אפשר לטפל באחד מהם מכאן. שום דבר לא יוצא בלי אישור.
```

### `alert.actions.button`
**מתי:** הכפתור שפותח את הרשימה.
```
בחירת פעולה
```

## 2. התראות דחופות

### `alert.urgent.mail`
**מתי:** מייל מאדם שהמשתמש כבר כתב אליו (Sent Items), שכותב במפורש שזה דחוף ("דחוף", "בהול", "urgent", "ASAP"…) או מסומן בחשיבות גבוהה — ואינו חשוד כפישינג.
**כפתורים:** `[לנסח תשובה]` `[להזכיר מחר]` `[בלי התראות]`
```
*מייל דחוף*
מ-{who}: {subject}

אפשר לנסח תשובה לאישור, או להזכיר מחר.
```

### `alert.urgent.conflict`
**מתי:** שתי פגישות חופפות ב-24 השעות הקרובות.
**משתנים:** `{day_label}` ("היום" / "ביום ה׳ 22.10")
**כפתורים:** `[לטפל בהתנגשות]` `[בלי התראות]`
```
*התנגשות ביומן {day_label}*
• {a}
• {b}

אפשר להזיז אחת מהן. כל שינוי מגיע קודם לאישור.
```

### `alert.template.mail`
**מתי:** מייל דחוף כשאין חלון 24 שעות פתוח — {{1}} של התבנית `proactive_alert` (שורה אחת). אותם כללים: עד 2 ביום, שעות שקטות, שבת וחג, "בלי התראות".
**כפתורים (בתבנית):** `[לטפל עכשיו]` (`al:reply:<id>`) `[בלי התראות]` (`al:off`)
```
מייל דחוף מ-{who}: {subject}
```

### `alert.template.conflict`
**מתי:** התנגשות ביומן כשאין חלון פתוח — {{1}} של `proactive_alert`.
**כפתורים (בתבנית):** `[לטפל עכשיו]` (`al:conf:<id>`) `[בלי התראות]` (`al:off`)
```
התנגשות ביומן {day_label}: {a} חופפת ל-{b}
```

## 3. אזהרת פישינג

### `alert.phishing.warning`
**מתי:** כשעלזה קוראת, מסכמת או מציגה מייל חשוד (`phishing_warning.say` בתוצאת הכלי — המודל פותח בה כלשונה). עלזה לא מבצעת שום בקשה מהמייל.
```
⚠️ שימו לב: {reasons}. כדאי לאמת בטלפון, מול מספר מוכר, לפני כל תשלום, ולא ללחוץ על קישורים במייל.
```

### `alert.phishing.marked`
**מתי:** אחרי `[לסמן כחשוד]` — קטגוריה ב-Outlook. לא מוחקים, לא מעבירים, לא עונים.
**משתנים:** `{category}` ("חשוד - פישינג")
```
סימנתי את המייל ב-Outlook בקטגוריה ״{category}״. לא מחקתי ולא העברתי אותו. כדאי לא ללחוץ על קישורים בו ולא להעביר תשלום לפני אימות בטלפון.
```

### `alert.phishing.mark_unavailable`
**מתי:** `[לסמן כחשוד]` בחשבון בלי הרשאת שינוי (Gmail — `gmail.readonly` בלבד) או כשהסימון נכשל.
```
בחשבון הזה אין לי הרשאה לסמן מיילים, אז רק הזהרתי. אפשר לסמן אותו כפישינג בתיבת המייל עצמה.
```

## 4. הסיבות (`{reasons}`)

עד 3, מופרדות ב-"; ". מקור: `phishingReasons` ב-`lib/copy/bot-proactive.ts`.

| אות | טקסט |
|---|---|
| `lookalike_domain` | כתובת השולח דומה ל-{x} אבל אינה זהה |
| `display_name_spoof` | השם בשולח נראה כמו {x}, אבל המייל הגיע מכתובת אחרת |
| `credential_link` | מבקשים להתחבר או לאמת חשבון דרך קישור חשוד |
| `bank_change` | מבקשים לשנות פרטי חשבון בנק לתשלום |
| `reply_to_mismatch` | תשובה למייל תגיע לכתובת אחרת מזו של השולח |
| `payment_urgency` | יש לחץ להעביר תשלום בדחיפות |
| `login_link` | מבקשים להתחבר דרך קישור (רק כשזו האות היחידה) |

## 5. שליטה של המשתמש

### `alert.off`
**מתי:** "בלי התראות" / "לכבות התראות" / `[בלי התראות]` / הכפתור באזור האישי (הגדרות).
```
בסדר, בלי התראות יזומות: לא אשלח התראות דחופות, וסיכום הבוקר יגיע בלי ״דברים שכדאי לא לפספס״. להחזיר אותן — ״להחזיר התראות״.
```

### `alert.on`
**מתי:** "להחזיר התראות" / "להפעיל התראות".
```
ההתראות חזרו: עד 2 התראות דחופות ביום, בין 08:00 ל-20:00 ולא בשבת ובחג, ו״דברים שכדאי לא לפספס״ בסיכום הבוקר.
```

### `alert.already_off`
```
ההתראות היזומות כבר כבויות. להחזיר אותן — ״להחזיר התראות״.
```

### `alert.already_on`
```
ההתראות היזומות פעילות. לכבות אותן — ״בלי התראות״.
```

### `alert.pro_only`
**מתי:** אחת הפקודות או לחיצה על כפתור של התראה, במסלול בסיסי או בתקופת ניסיון.
```
התראות יזומות מהמייל ומהיומן ואזהרות פישינג כלולות במסלול פרו. לשדרוג אפשר לכתוב ״שדרוג״.
```

### `alert.gone`
**מתי:** כפתור של פריט שכבר לא קיים (נמחק אחרי 30 יום, או מזהה של משתמש אחר).
```
הפריט הזה כבר לא זמין. אפשר פשוט לכתוב לי מה צריך.
```

## 6. מה כפתור מבקש מעלזה

הכפתורים שדורשים ניסוח לא מפעילים פעולה: הם הופכים לבקשה רגילה לעוזרת, שעוברת את אותו מסלול כמו בקשה מוקלדת — וכל פעולה יוצאת מגיעה כטיוטה עם כפתורי אישור.

### `alert.request.reply`
```
לנסח תשובה למייל מ-{who} בנושא "{subject}" (מזהה המייל[ ב-Gmail]: {message_id}). קודם לקרוא את המייל, ואז להכין טיוטת תשובה לאישור.
```

### `alert.request.brief`
```
תדריך קצר לפגישה {meeting} עם {who}: מה היה בינינו במייל לאחרונה, ומה כדאי לזכור לפני הפגישה.
```

### `alert.request.conflict`
```
יש התנגשות ביומן: {a} חופפת ל-{b}. לעזור להזיז אחת מהן, בטיוטה לאישור.
```

### `alert.reminder.reply`
**מתי:** טקסט התזכורת של `[להזכיר מחר]` (מחר ב-9:00, דרך שירות התזכורות; ההד: `act.reminder.set`).
```
לחזור ל{who}: {subject}
```

### `alert.reminder.deadline`
**מתי:** טקסט התזכורת של `[תזכורת למועד]` (יום לפני המועד ב-9:00; אם כבר מאוחר — בבוקר המועד ב-8:00; אם גם זה עבר — בעוד שעה).
```
מועד {when}: {subject}
```
