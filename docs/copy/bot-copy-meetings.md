# טקסטים — סיכומי פגישות (מסלול פרו)

> משלים את `bot-copy.md` ואת `bot-copy-proactive.md` (אותן מוסכמות: פנייה ניטרלית, עלזה בלשון נקבה, בלי "שלח/י"). מיושם ב-`lib/copy/bot-meetings.ts` (`mcopy`), ומבחן מוודא שכל מזהה מתועד כאן.
> מה זה: אחרי פגישת Teams או Google Meet, עלזה לוקחת את התמליל שהפלטפורמה עצמה שמרה (שום בוט לא מצטרף לפגישה), מסכמת בעברית ומציעה בכפתורים מייל סיכום למשתתפים (טיוטה לאישור), מסמך משימות והוספת המשימות לרשימה. רק בפרו (`entitlements.meetingSummaries`, נבדק בשרת). Zoom — בקרוב. הקוד: `lib/meetings`.
> שם הפגישה, שמות המשתתפים ושורות הסיכום מגיעים מהיומן ומהתמליל, ועוברים `oneLineUntrusted` (שורה אחת, מנוקה, מקוצרת) לפני שהם נכנסים לטקסט.

## מתי נשלח מה

| מה | מתי | ערוץ |
|---|---|---|
| סיכום אוטומטי | 10 דקות אחרי סוף פגישה מקוונת (Teams ביומן Microsoft 365, Meet ביומן Google) שיש לה תמליל; אם התמליל עוד לא מוכן — שוב אחרי 15, 30 ו-60 דקות, ואז מוותרים בשקט | בתוך חלון 24 השעות: הסיכום כטקסט ואחריו כפתורי הפעולות. מחוץ לחלון: התבנית `meeting_summary_ready` (`docs/copy/wa-templates.md`). רק 08:00–20:00, לא בשבת ובחג — פגישה שנגמרה ב-19:45 מסוכמת בבוקר |
| סיכום לפי בקשה | "סיכום של הפגישה האחרונה", "תסכמי את הפגישה עם כהן" (הכלי `meeting_summary`) | מיד, בלי שעות שקטות; כשאין סיכום — מסבירים למה |
| כיבוי | "בלי סיכומי פגישות" (או הכפתור בתבנית) | הסיכום האוטומטי נעצר; סיכום לפי בקשה ממשיך לעבוד |

סיכום אוטומטי לא מסביר אף פעם למה אין סיכום (רוב הפגישות לא מתומללות). שום דבר לא יוצא לאדם אחר בלי אישור.

## 1. הסיכום

### `mt.summary`
**מתי:** הסיכום עצמו, בתוך החלון (או אחרי "לראות את הסיכום"). סעיף ריק לא מוצג.
**משתנים:** `{title}`, `{when}` ("יום ה׳ 22.10, 10:00"), `{platform}` (Teams / Google Meet), `{summary}`, `{decisions}`, `{actions}` (`mt.action_line`), `{questions}`
```
*סיכום הפגישה: {title}*
{when} · {platform}

{summary}

*החלטות*
• {decision}

*משימות*
• {action}

*שאלות פתוחות*
• {question}
```
פגישה ארוכה מאוד (יותר משמונה חלקים של תמליל) מוסיפה בסוף: "(הפגישה ארוכה במיוחד, והסיכום מכסה את רובה.)"

### `mt.action_line`
**מתי:** שורת משימה בסיכום, במייל ובמסמך. האחראי והתאריך רק כשנאמרו בפגישה.
```
{task} ({owner}, עד {due})
```

### `mt.actions.body`
**מתי:** ההודעה עם הכפתורים, מיד אחרי הסיכום.
**כפתורים:** `[מייל למשתתפים]` (`mt:mail:<id>`, כשיש משתתפים עם מייל), `[מסמך משימות]` (`mt:doc:<id>`) ו-`[להוסיף למשימות]` (`mt:tasks:<id>`) — שני האחרונים רק כשיש משימות.
```
מה לעשות עם הסיכום? שום דבר לא יוצא בלי אישור.
```

## 2. מייל הסיכום (טיוטה לאישור)

### `mt.mail.subject`
```
סיכום פגישה: {title}
```

### `mt.mail.body`
**מתי:** אחרי `[מייל למשתתפים]` — טיוטת `send_mail` בשם המשתמש, אל המשתתף הראשון ועותק לשאר, מוצגת עם `[שלח] [ערוך] [בטל]` כמו כל טיוטה.
```
שלום לכולם,

תודה על הפגישה ({title}, {date}). הנה סיכום קצר:

{summary}

החלטות:
• {decision}

משימות:
• {action}

שאלות פתוחות:
• {question}

אם משהו חסר או לא מדויק, אשמח לתיקון.

בברכה,
{signature}
```

### `mt.mail.no_attendees`
```
בפגישה הזו אין משתתפים נוספים עם כתובת מייל, ולכן אין למי לשלוח את הסיכום.
```

## 3. מסמך המשימות

### `mt.doc.title`
**מתי:** שם ה-Google Doc ב-Drive של המשתמש (פרו, `drive.file` — מסמך שעלזה יוצרת, לא משותף עם אף אחד).
```
משימות מהפגישה - {title} ({date})
```

### `mt.doc.body`
```
משימות מהפגישה: {title}
{date}

משימות
☐ {action}

החלטות
• {decision}

שאלות פתוחות
• {question}
```

### `mt.doc.saved`
```
שמרתי את מסמך המשימות ב-Google Drive: ״{name}״.
{link}
```

### `mt.doc.in_chat`
**מתי:** אין חיבור Google עם שמירת קבצים (ב-Microsoft 365 אין כאן הרשאת כתיבה ל-OneDrive): הרשימה בשיחה.
```
בחשבון הזה אין לי אפשרות לשמור מסמך חדש, אז הנה רשימת המשימות מהפגישה ״{title}״, מוכנה להעתקה:

☐ {action}
```

### `mt.doc.already`
```
מסמך המשימות של הפגישה הזו כבר נשמר.
```

## 4. משימות ברשימה

### `mt.tasks.added`
**מתי:** אחרי `[להוסיף למשימות]` — Microsoft To Do (Tasks.ReadWrite) או Google Tasks, קודם של הפלטפורמה של הפגישה. פעם אחת לכל סיכום.
```
הוספתי {count} משימות ל-{service}:
• {task}
```

### `mt.tasks.partial`
```
הוספתי {added} מתוך {total} משימות ל-{service}. את השאר לא הצלחתי להוסיף, ואפשר לבקש שוב בעוד כמה דקות.
```

### `mt.tasks.already`
```
המשימות מהפגישה הזו כבר נוספו לרשימה.
```

### `mt.tasks.unavailable`
```
כדי להוסיף משימות צריך את Google Tasks או את Microsoft To Do בחשבון המחובר. בינתיים אפשר לבחור ״מסמך משימות״.
```

### `mt.empty`
```
בפגישה הזו לא עלו משימות מוגדרות.
```

## 5. סיכום לפי בקשה

### `mt.queued`
**מתי:** הכלי `meeting_summary` מצא את הפגישה (מקוונת, הסתיימה בשבועיים האחרונים) — הסיכום מגיע בהודעה נפרדת.
```
מכינה את הסיכום של ״{title}״ ({when}). זה לוקח דקה או שתיים, והוא יגיע כאן.
```

### `mt.not_found`
```
לא מצאתי פגישה מקוונת שהסתיימה בשבועיים האחרונים ומתאימה ל״{query}״. אפשר לכתוב את שם הפגישה או את שם אחד המשתתפים.
```

### `mt.not_ended`
```
הפגישה ״{title}״ עוד לא הסתיימה. כשהיא תסתיים והתמליל יהיה מוכן, אשלח את הסיכום כאן.
```

### `mt.zoom_soon`
```
סיכום של פגישות Zoom עוד לא זמין (בקרוב). כרגע אפשר לסכם פגישות Teams ו-Google Meet.
```

### `mt.other_platform`
```
אפשר לסכם רק פגישות Teams ו-Google Meet. לפגישה הזו אין קישור של אחת מהן.
```

## 6. למה אין סיכום (רק כשביקשו)

### `mt.no_transcript`
**מתי:** התמלול לא הופעל בפגישה (או שהתמליל לא הגיע גם שעתיים אחרי הסוף).
```
לא נמצא תמליל של ״{title}״. הסיכום נבנה מהתמליל ש-{platform} שומרת, ולכן צריך להפעיל תמלול בפגישה עצמה (ב-Teams: ״התחלת תמלול״; ב-Meet: ״תמליל״, בחשבונות Google Workspace שכוללים אותו).
```

### `mt.not_ready`
**מתי:** פעם אחת, בבקשה שהגיעה מיד אחרי הפגישה — הניסיון הבא בעוד 15 דקות.
```
התמליל של ״{title}״ עוד לא מוכן. אנסה שוב בעוד כמה דקות, והסיכום יגיע כאן.
```

### `mt.no_access`
**מתי:** Graph / Drive סירבו (בדרך כלל: לא המארגן, או פגישה של ארגון אחר).
```
אין לי גישה לתמליל של ״{title}״. בדרך כלל רק מי שארגן את הפגישה יכול לקרוא את התמליל שלה.
```

### `mt.consent.teams`
**מתי:** בחיבור Microsoft 365 אין את זוג ההרשאות של התמלילים (חיבור מלפני הפרו, או לפני התכונה). קישור חיבור מחדש — חיבור של משתמש פרו מבקש אותן.
```
כדי לסכם פגישות Teams צריך הרשאה נוספת: קריאת תמלילי פגישות. חיבור מחדש לוקח חצי דקה:
{link}
```

### `mt.consent.teams_admin`
**מתי:** בחיבור האחרון הארגון דרש אישור מנהל להרשאת התמלילים (`profile.ms_meetings_consent = "admin_required"`), והחיבור הושלם בלעדיה.
```
כדי לסכם פגישות Teams צריך הרשאה לקריאת תמלילי פגישות, ובארגון שלך רק מנהל ה-IT יכול לאשר אותה. אפשר להעביר לו את הקישור הזה (אישור חד-פעמי לכל הארגון):
{admin_link}
אחרי האישור צריך לחבר את החשבון מחדש — ״חבר שוב״.
```

### `mt.consent.meet`
**מתי:** בחיבור Google אין `drive.readonly`. אחריו בא הטקסט של `g.drive_read.consent` עם הקישור (או השורה שהקריאה לא זמינה כרגע).
```
כדי לסכם פגישות Google Meet צריך הרשאה לקרוא את התמליל ש-Meet שומרת ב-Drive.
```

### `mt.failed`
```
לא הצלחתי להכין את הסיכום הפעם. אפשר לבקש שוב בעוד כמה דקות.
```

## 7. שליטה של המשתמש

### `mt.off`
```
בסדר, בלי סיכומי פגישות אוטומטיים. אפשר עדיין לבקש סיכום של פגישה מסוימת, ולהחזיר אותם — ״להחזיר סיכומי פגישות״.
```

### `mt.on`
```
סיכומי הפגישות חזרו: אחרי כל פגישת Teams או Google Meet עם תמליל, הסיכום יגיע כאן.
```

### `mt.already_off`
```
סיכומי הפגישות האוטומטיים כבר כבויים. להחזיר אותם — ״להחזיר סיכומי פגישות״.
```

### `mt.already_on`
```
סיכומי הפגישות פעילים. לכבות אותם — ״בלי סיכומי פגישות״.
```

### `mt.pro_only`
```
סיכומי פגישות Teams ו-Google Meet כלולים במסלול פרו. לשדרוג אפשר לכתוב ״שדרוג״.
```

### `mt.gone`
```
הסיכום הזה כבר לא זמין (סיכומים נשמרים 30 יום). אפשר לבקש סיכום חדש של הפגישה.
```

## כפתורים

| כפתור | payload | מה קורה |
|---|---|---|
| מייל למשתתפים | `mt:mail:<id>` | טיוטת מייל לאישור (`mt.mail.*`) |
| מסמך משימות | `mt:doc:<id>` | Google Doc ב-Drive, או הרשימה בשיחה |
| להוסיף למשימות | `mt:tasks:<id>` | To Do / Google Tasks, פעם אחת |
| לראות את הסיכום | `mt:show:<id>` | (בתבנית) הסיכום המלא עם הכפתורים |
| בלי סיכומי פגישות | `mt:off` | (בתבנית) כיבוי הסיכום האוטומטי |
