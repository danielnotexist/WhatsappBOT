# טקסטים — AI חי בהדגמה והצ'אט באתר

> משלים את `bot-copy.md` (אותן מוסכמות). הטקסטים מוצגים גם בעמוד הצ'אט באתר (`/demo/chat`), ולכן רק מקף קצר.
> המימוש: `lib/copy/bot-live.ts`. התקרות עצמן: `lib/ai/budget.ts`.

### `budget.daily_cap_demo`
**מתי:** במצב הדגמה עם AI חי (`LIVE_AI=1`) הסכום היומי של קריאות המודל והתמלול הגיע ל-`AI_DAILY_BUDGET_USD` (ברירת מחדל 3 דולר). לא נעשית קריאה.
```
הגענו לתקרת הבדיקות של היום. אפשר להמשיך מחר.
```

### `budget.daily_cap`
**מתי:** מחוץ להדגמה, כשהמפעיל הגדיר `AI_DAILY_BUDGET_USD` והסכום היומי הגיע אליו. לא נעשית קריאה.
```
הגענו לתקרת השימוש של היום. אפשר להמשיך מחר.
```

### `budget.user_cap_demo`
**מתי:** במצב הדגמה עם AI חי, המשתמש הגיע ל-`DEMO_USER_DAILY_MESSAGES` הודעות שהגיעו למודל או לתמלול היום (ברירת מחדל 60). לא נעשית קריאה.
**משתנים:** `{limit}`
```
הגענו ל-{limit} הודעות היום, המכסה של גרסת הבדיקה. אפשר להמשיך מחר.
```
