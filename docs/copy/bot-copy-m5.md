# תוספות טקסט — אבן דרך 5 (תזכורות, סיכום בוקר, הקלטות)

> משלים את `bot-copy.md` (אותן מוסכמות). המחרוזות כאן חדשות; כל השאר (§4.4, §4.5, `err.transcription_failed`) כבר מתועדות ב-`bot-copy.md` ומיושמות ב-`lib/copy/bot-m5.ts`. כשנאחד את המסמכים — להעביר את הסעיפים האלה ל-`bot-copy.md` §4.4/§4.5.

### `act.reminder.set_recurring`
**מתי:** נקבעה תזכורת חוזרת ("כל יום בשמונה"). מהדהדים את הכלל ואת המופע הראשון כזמן מוחלט.
**משתנים:** `{rule}` ("כל יום, 8:00" / "בימים א׳–ה׳, 7:30" / "כל יום א׳, 9:00"), `{first_abs}`, `{text}`
```
אזכיר: {text}
{rule}
הפעם הראשונה: {first_abs}
```

### `act.reminder.set_small_hours`
**מתי:** תזכורת ל"מחר" שנקבעה בין 00:00 ל-04:59 (שעון ישראל). רוב האנשים מתכוונים לבוקר הקרוב — זה מה שנקבע — אבל ההד מציין את התאריך המפורש, ובכפתור אחד אפשר להעביר ליום שאחריו. בלי לנחש בשקט ובלי לספר על תיקונים (בדיקה חיה של דניאל, 23.10.2026, 03:43).
**משתנים:** `{when_abs}` (עם תאריך: "היום, יום ו׳ 23.10, 9:00"), `{text}`, `{next_day}` ("יום ש׳ 24.10")
```
אזכיר: {text}
{when_abs}

אחרי חצות "מחר" הוא בדרך כלל הבוקר הקרוב. אם הכוונה ל{next_day} — אפשר להעביר בלחיצה.
```
`[ל{next_day}]` (`rem:next:<reminder_id>`)

### `act.reminder.moved`
**מתי:** אחרי לחיצה על `[ל{next_day}]`. התזכורת עברה לאותה שעה ביום שאחרי; לחיצה נוספת לא מזיזה שוב.
**משתנים:** `{when_abs}` (עם תאריך: "מחר, יום ש׳ 24.10, 9:00")
```
הועבר. אזכיר {when_abs}.
```

### `act.reminder.past_time`
**מתי:** הזמן שהתבקש כבר עבר ("היום ב-8" בשעה 21:00).
**משתנים:** `{when_abs}`
```
{when_abs} כבר עבר. מתי להזכיר במקום?
```

### `act.reminder.cancelled`
**מתי:** תזכורת בוטלה לבקשת המשתמש.
**משתנים:** `{text}`
```
התזכורת "{text}" בוטלה.
```

### `act.reminder.which`
**מתי:** בקשת ביטול שמתאימה ליותר מתזכורת אחת.
**משתנים:** רשימה `{when_abs}`, `{text}`
```
יש כמה תזכורות שמתאימות:
• {when_abs} — {text}
• {when_abs} — {text}

איזו מהן לבטל?
```

### `act.reminder.not_found`
**מתי:** בקשת ביטול שלא מתאימה לאף תזכורת פתוחה.
```
לא מצאתי תזכורת פתוחה כזו. כדי לראות את כולן — "אילו תזכורות יש לי?"
```

### `act.reminder.limit`
**מתי:** למשתמש כבר 100 תזכורות פתוחות.
```
יש כבר הרבה תזכורות פתוחות. כדאי לבטל כמה מהן לפני שמוסיפים חדשות.
```

### `act.morning.stopped`
**מתי:** "תפסיק את סיכום הבוקר" (הגרסה השנייה של `act.morning.time_changed` ב-`bot-copy.md`, עם id משלה).
```
סיכום הבוקר הופסק. להפעיל שוב — "סיכום בוקר ב-7:30".
```

## כפתורי תזכורת

| id | כותרת (בתוך החלון) | כותרת בתבנית `reminder` |
|---|---|---|
| `rem:done:<reminder_id>` | טופל | בוצע |
| `rem:hour:<reminder_id>` | דחה לשעה | עוד שעה |
| `rem:tmrw:<reminder_id>` | דחה למחר | מחר בבוקר |
| `rem:next:<reminder_id>` | ל{next_day} (למשל "ליום ש׳ 24.10") — רק עם `act.reminder.set_small_hours` | — |

בשעות 00:00–04:59 כל הד של "היום" / "מחר" מוסיף את התאריך ("היום, יום ו׳ 23.10, 9:00"), כי בשעות האלה המילים לבדן דו-משמעיות.

בתבנית, ה-id נשלח כ-`payload` של ה-quick reply וחוזר ב-webhook כ-`button.payload`.
