# כיווני עיצוב לדף הנחיתה — דניאל בוחר אחד

שלושה דפי HTML עצמאיים (RTL, mobile-first, מצב כהה אוטומטי, הדגמת שיחה מונפשת בעברית ב-hero עם fallback ל-`prefers-reduced-motion`). כולם באותו מבנה (PLAN §1: hero עם טלפון → איך זה עובד → יכולות → פרטיות → מחירים → שאלות → CTA) ובאותם טקסטים, כך שההבדל הוא רק באופי החזותי. שם המוצר מופיע כ-`{{שם}}` עד שייבחר.

פותחים את הקובץ בדפדפן (צריך אינטרנט לפונטים מ-Google Fonts). צילומי מסך ב-`screenshots/` (375 ו-1280, בהיר וכהה); ליצירה מחדש: `node design/directions/screenshot.mjs` (דורש Playwright + Chromium מותקנים; הסקריפט גם בודק שאין גלילה אופקית).

## 01 — משרד שקט (`01-quiet-office.html`)

שמנת וזית, Frank Ruhl Libre לכותרות ו-Assistant לגוף. עמוד "עריכתי": קווי שיער דקים פותחים כל סקשן, מספרי צעדים גדולים, כמעט בלי צללים ועיגולים. ההדגמה בטלפון היא המקום היחיד עם תנועה.
**יתרונות:** נראה כמו משרד עורכי דין ותיק — אמין, רציני, מתאים ל"מקצועי וחם בלי בדיחות". קל לקרוא טקסטים ארוכים, מתורגם היטב לחומרים מודפסים.
**חסרונות:** הכי פחות "מוצר טכנולוגי"; עלול להיראות מיושן למי שרגיל ל-SaaS; הסריף העברי קטן נראה פחות טוב במסכים זולים.
**קהלים:** עורכי דין, רואי חשבון, נוטריונים, שמאים — מי שמוכר אמינות ומסורת.

## 02 — כחול לילה (`02-night-blue.html`)

נייבי עמוק ולימון חומצי, Suez One לכותרות ו-IBM Plex Sans Hebrew לגוף. hero כהה עם כתמי צבע נעים, רצועת ticker של דוגמאות לבקשות, דוגמת "יומן פעולות" בסקשן הפרטיות, כרטיסים עם מסגרות.
**יתרונות:** הכי "מוצר": נועז, זכיר, בולט בפיד; הניגודיות החזקה עובדת טוב בטלפון; מראה טכנולוגי שמדבר ליועצים וסטארטאפיסטים.
**חסרונות:** הכי רחוק מ"חם"; לימון על נייבי מעייף בטקסטים ארוכים; יותר תנועה = יותר דברים שיכולים להישבר; עלול להרתיע קליניקות ועו"ד שמרנים.
**קהלים:** יועצים עסקיים, סוכני ביטוח ונדל"ן, עסקים טכנולוגיים קטנים.

## 03 — קליניקה חמה (`03-warm-clinic.html`)

אפור חם, טורקיז עמוק כצבע העבודה ואקסנט אלמוגי אחד לכל מסך (CTA, מספרי צעדים, קו מתחת לכותרת). Karantina (דחוס ודרמטי) רק לכותרת הראשית ולמחירים, Heebo לכל השאר. הכול מעוגל: כרטיסים, כפתורי pill, עיגולי אייקונים, צללים רכים; הדגמת השיחה כוללת הודעה קולית שמתומללת; בנייד יש סרגל CTA דביק בתחתית.
**יתרונות:** הכי חם ונגיש בלי לאבד מקצועיות; מרגיש כמו קליניקה/משרד מודרני ולא כמו תוכנה; הטורקיז קרוב לירוק של וואטסאפ ומרגיש "שייך"; mobile-first ביותר מבין השלושה.
**חסרונות:** Karantina חזק ועלול להיראות "פרסומי" אם מגזימים בו; ה"ידידותי" עלול להיתפס פחות יוקרתי אצל משרדי עו"ד גדולים; צריך איור/דמות כדי שהריקנות בסקשן הפרטיות תתמלא.
**קהלים:** קליניקות (פיזיותרפיה, פסיכולוגיה, תזונה), יועצים עצמאיים, משרדים קטנים של אדם אחד.
