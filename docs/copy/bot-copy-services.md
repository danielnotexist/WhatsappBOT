## 2. אתר: שורת השירותים ב"חיבורים" (`/account`)

מתחת לכל חשבון מחובר: אייקון לכל שירות. ריחוף, פוקוס במקלדת או נגיעה מציגים בועה קטנה. השורה הראשונה היא גם השם הנגיש של האייקון (`aria-label`), והשנייה (ושורת הפעולה, כשיש) היא התיאור (`aria-describedby`).

**שורת הפעולה** (רק ב"צריך אישור נוסף", האייקון הוא קישור): Google - `לחיצה פותחת את האישור ב-Google`; Microsoft - `לחיצה פותחת חיבור מחדש ב-Microsoft. בארגון ייתכן שיידרש אישור מנהל`. בנגיעה (טלפון) הנגיעה הראשונה מציגה את הבועה והשנייה פותחת את האישור.

**מתחת לשורה,** כשיש שירות שמחכה לאישור: `שירות אחד מחכה לאישור נוסף` / `{n} שירותים מחכים לאישור נוסף`.

**סטטוסים:** `מחובר` · `צריך אישור נוסף` (לחיצה פותחת את האישור) · `לא זמין` · `במסלול פרו` (לחיצה פותחת את השדרוג: קישור התשלום האישי; שורת הפעולה `לחיצה פותחת את השדרוג לפרו`).

**במסלול פרו** (בבסיסי ובתקופת הניסיון, לפי `entitlements` ב-`lib/billing/plans.ts`): Google Tasks, Microsoft To Do, SharePoint ו-Google Docs / Sheets / Slides. השורה השנייה היא מה שהשירות עושה. בבסיסי Google Drive נשאר `מחובר` עם `קבצים שנפתחו דרכי. חיפוש בכל ה-Drive ושמירת מסמכים: במסלול פרו`, וקבצי Word, Excel ו-PowerPoint עם `קריאה של מסמכים, גיליונות ומצגות מ-OneDrive. SharePoint: במסלול פרו`. בחשבון שני שמושהה (חובר לפני החלוקה) כל השירותים `במסלול פרו`, עם `במסלול הנוכחי עובדים עם חשבון אחד. Google ו-Microsoft יחד: במסלול פרו`.

| שירות | שורה ראשונה | מחובר | צריך אישור נוסף | לא זמין / חלקי |
|---|---|---|---|---|
| Gmail | `Gmail - מחובר` | קריאה, חיפוש וסיכום של מיילים, ושליחה אחרי אישור | השליחה פעילה. קריאה וסיכום של מיילים מחכים לאישור | (מחובר) שליחת מיילים אחרי אישור |

- כשקריאת Gmail או Drive כבויה או שהתקרה מלאה, Gmail ו-Drive נשארים "מחובר" עם מה שעובד, ו-Docs / Sheets / Slides "לא זמין".
- כותרת הרשימה לקורא מסך: `שירותים ב-Google` / `שירותים ב-Microsoft 365`.

## 3. אתר: חשבון אחד בבסיסי ובתקופת הניסיון

- **`/account`, חשבון שני שאפשר לחבר רק בפרו:** במקום "חיבור" - `במסלול פרו` (קישור התשלום), ומתחת לשם `Gmail בנוסף לחשבון המחובר: במסלול פרו` / `Outlook בנוסף לחשבון המחובר: במסלול פרו`. מתחת לרשימה: `במסלול הבסיסי מחברים חשבון אחד: Google או Microsoft. שניהם יחד: במסלול פרו.` (בניסיון: `בתקופת הניסיון ובמסלול הבסיסי ...`).
- **`/account`, שני חשבונות מחוברים מלפני החלוקה:** הודעה מעל הרשימה: `במסלול הבסיסי עובדים עם חשבון אחד. עכשיו פעיל {החדש מביניהם}, ו-{השני} מחובר אבל מושהה. אפשר לנתק את אחד מהם, או לשדרג לפרו ולעבוד עם שניהם יחד.` + `לשדרוג לפרו`. בשורת החשבון המושהה: `מושהה: במסלול הבסיסי עובדים עם חשבון אחד`.
- **דף התשלום (`/pay/<token>?why=`), אחרי חיבור שה-start route דחה:**
  - `second_account`: `בתקופת הניסיון ובמסלול הבסיסי עובדים עם חשבון אחד: Google או Microsoft. שניהם יחד כלולים במסלול פרו. אפשר גם להחליף חשבון: לנתק את החשבון המחובר באזור האישי, ואז לחבר את השני.`
  - `pro_feature`: `השירות הזה כלול במסלול פרו. אחרי השדרוג אפשר לאשר אותו מהאזור האישי.`
- **שלב החיבור בהרשמה (`/start/connect`) עם חשבון מחובר:** `{Microsoft 365 / Google} כבר מחובר. בתקופת הניסיון ובמסלול הבסיסי עובדים עם חשבון אחד, ושני החשבונות יחד כלולים במסלול פרו.` + `להמשיך`.
- **כרטיס המנוי ב-`/account`:** `מה כלול במסלול` / `מה כלול בתקופת הניסיון` (מקופל), עם שורות המסלול מ-`planFeatures`, ובבסיסי ובניסיון גם `במסלול פרו, בנוסף:`.
