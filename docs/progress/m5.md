### 2026-10-21 — אבן דרך 5

**מה נעשה**
- **פענוח זמן בעברית (`lib/reminders/parse.ts`)** — דטרמיניסטי, לא המודל: "מחר ב-9", "עוד שעתיים", "ביום ראשון הבא ב-8:30", "כל יום בשמונה", "בעוד רבע שעה", "ב-14:00", "ברבע לתשע", "ב-5 אחה״צ", "הערב", "ב-22.10", "ב-5 בנובמבר", "בימים א׳–ה׳ ב-7:30", "כל חודש ב-1", ISO. אזור זמן Asia/Jerusalem עם מעבר שעון נכון (`lib/time/zoned.ts`, Intl בלבד): שעה שלא קיימת (27.3.2026 02:30) → 03:30; שעה כפולה (25.10.2026 01:30) → המופע הראשון. הד זמן מוחלט: "מחר, 9:00" / "יום ה׳ 23.10, 16:30".
  - מוסכמות (מתועדות בראש הקובץ): דקות/שעות = זמן שחלף; ימים/שבועות/חודשים = אותה שעת קיר. שעה 1–5 בלי ציון = אחה״צ; 6–11 = בוקר, או ערב אם הבוקר כבר עבר היום; "09:00" מדויק. יום בלי שעה → 9:00 (בבוקר 9, בצהריים 12, אחה״צ 16, בערב 20, בלילה 22). "ביום ראשון" = הקרוב (היום אם עוד לא עבר), "ביום ראשון הבא" מדלג על היום. "מחר" בין 00:00 ל-04:00 = הבוקר הקרוב. "היום" בלי שעה / בלי זמן בכלל → שואלים (`act.reminder.set_ambiguous_time`).
- **תזכורות (`lib/reminders/service.ts`)**: יצירה (חד-פעמית/חוזרת), רשימה, ביטול (לפי מזהה או טקסט; כמה התאמות → שואלים), דחייה לשעה / למחר בבוקר, "טופל". משימת `reminder`: בתוך חלון 24 שעות — "⏰ תזכורת: …" עם [טופל] [דחה לשעה] [דחה למחר]; מחוצה לו — תבנית `reminder` (ה-id של התזכורת ב-payload של ה-quick replies). אידמפוטנטית (`last_fired_at`, בדיקת `due_at` מול ה-payload), תזכורת חוזרת מתזמנת את המופע הבא על שעון הקיר. משתמש שכיבה הודעות יזומות (`proactive_disabled`) — התזכורת מבוטלת.
- **כלים למודל (`lib/ai/reminder-tools.ts`)**: `create_reminder` (המודל מעביר את ביטוי הזמן כפי שנכתב), `list_reminders`, `cancel_reminder`; נרשמו ב-`BASE_TOOLS` (זמינים גם בלי חיבור). התשובה המדויקת חוזרת ב-`reply`.
- **סיכום בוקר (`lib/jobs/morning-summary.ts`)**: א׳–ה׳ בשעה שנבחרה; פגישות היום (calendarView ליום המקומי; במיזוג עם אבן דרך 6 נוסף גם יומן Google — `googleFor` → `listEvents`, ממוזג לפי שעה), מיילים שמחכים לתשובה (היוריסטיקה: 7 ימים אחרונים, מאדם — לא no-reply/ניוזלטר/המשתמש עצמו, שיחה שלא נענתה מאז לפי Sent Items, ולא נקרא או שואל משהו), תזכורות של היום. מחוץ לחלון — תבנית `morning_summary`, בתוכו — טקסט חופשי עם ה-closer לפי המצב. Opt-in: רק `morning_summary_enabled === true` ("לא עכשיו" = כבוי); מכבד השהיה (`proactive_paused_until`); שעה שהשתנתה / יום אחר / סופ״ש → דילוג; אחד ליום למשתמש (dedupe key + `morning_summary_last_date`); בלי חיבור ובלי תזכורות — לא שולחים.
- **תזמון**: `morning_summary:<user>:<YYYY-MM-DD>:<HHMM>` — נוצר ע״י `schedule_morning_summaries()` ב-SQL (pg_cron כל 10 דק׳, מיגרציה 0005), אחרי כל ריצה (המופע הבא), ובבחירת שעה ב-onboarding / בכלי `set_morning_time` (מבטל משימות ישנות ומתזמן מחדש).
- **הודעות קוליות (`lib/stt/*`, `lib/bot/voice.ts`)**: "מקשיבה…" → הורדת המדיה מוואטסאפ (עד 20MB) → Soniox async (`stt-async-v5`, `language_hints: ["he","en"]`; העלאה → יצירה → polling → transcript → מחיקת התמלול והקובץ אצל Soniox) → גיבוי gpt-4o-transcribe → mock. התמלול נשמר ב-`messages.transcript` וממשיך בצינור כטקסט (גם בתשובות onboarding). הקלטה ארוכה (>20 שנ׳) או ביטחון נמוך → `proc.transcript_echo`. כישלון → `err.transcription_failed`, לא נספר בניסיון.
- **Routes**: `/api/jobs/run` — נוספו `reminder` ו-`morning_summary` (עריכה מינימלית). חדש: `/api/jobs/tick` — `claim_due_jobs` → פרסום ל-`/api/jobs/run` דרך התור (המסלול החלופי בלי pg_net, ולולאת הפיתוח ב-DATA_MODE=memory, שם לא צריך סוד).
- **תבניות (`lib/wa/templates.ts`)**: מטענים ל-`reminder`/`morning_summary`, הגדרות 7 התבניות + רישום ב-dry-run כברירת מחדל; בדיקה משווה מול ה-JSON ב-`docs/copy/wa-templates.md`.
- **DB**: מיגרציה `0005_m5_reminders_morning.sql` (0004 נשאר פנוי בכוונה) — `reminders.recurrence`, `reminders.last_fired_at`, סטטוס `done`, `schedule_morning_summaries()` + cron. שכבת הנתונים: `createReminder/getReminder/updateReminder/listReminders`, `claimDueJobs`, `cancelJob`, `setMessageTranscript` (memory + supabase). בדיקת SQL: `supabase/tests/m5_reminders.test.sql`.
- **טקסטים**: `lib/copy/bot-m5.ts`; מזהים חדשים מתועדים ב-`docs/copy/bot-copy-m5.md` (כדי לא לגעת ב-`bot-copy.md` בזמן העבודה המקבילה).
- **בדיקות**: 146 → 300 (154 חדשות): 103 לפענוח הזמן והחזרות (חצות, שישי/שבת, מעברי שעון 2026–2027), תזכורות, סיכום בוקר עם fixtures של Graph ושעון מדומה, STT עם fetch מדומה, הודעות קוליות בצינור, routes.

**דרוש מדניאל**
1. **תבניות Meta**: להחליף את APP_DOMAIN (השם עלזה כבר בטקסט, מ-`lib/brand.ts`) ולרשום את `morning_summary` ו-`reminder` (וגם החמש האחרות) — `registerTemplates({ dryRun: false, … })` ב-`lib/wa/templates.ts` או ידנית ב-WhatsApp Manager. בלי תבנית מאושרת, תזכורת/סיכום מחוץ לחלון ייכשלו.
2. **Soniox**: `SONIOX_API_KEY` (console.soniox.com). אופציונלי: `OPENAI_API_KEY` לגיבוי gpt-4o-transcribe.
3. **Supabase**: להריץ את מיגרציה 0005 (pg_cron/pg_net פעילים; cron `wabot_schedule_morning_summaries` נוצר אוטומטית). Vault `jobs_worker_url` = `https://<domain>/api/jobs/run` (כבר מאבן דרך 3).
4. **לבדיקה בטלפון**: סיכום ב-07:30, תזכורת מחוץ לחלון (תבנית), הקלטה בעברית.
