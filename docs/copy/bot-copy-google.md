> מחרוזות משותפות לשני הספקים נשארות ב-`bot-copy.md` ומקבלות את הספק כמשתנה: `onb.connect_link`, `err.connection_expired`, `err.provider_down`, `err.not_connected`, `act.cal.*`.

## 1. וואטסאפ

### `g.connect_done`
**מתי:** אחרי callback מוצלח של Google, אם יש מספר וואטסאפ מקושר. רשימת היכולות נבנית לפי ההרשאות שאושרו בפועל (granular consent).
**משתנים:** `{account_email}`, רשימת יכולות.
```
החיבור ל-Google הושלם ({account_email}).
מעכשיו אפשר לבקש ממני:
• יומן Google — הצגה, קביעה, הזזה וביטול של פגישות
• קבצים ב-Drive שנוצרו או נפתחו דרכי
• שליחת מיילים מ-Gmail, אחרי אישור בכפתור
את תיבת ה-Gmail עצמה אני לא קורא בשלב זה.
```

### `g.connect_partial`
**מתי:** מיד אחרי `g.connect_done`, כשהמשתמש הוריד סימון מאחת ההרשאות במסך של Google.
**משתנים:** רשימת יכולות חסרות, `{link}` (קישור חד-פעמי ל-30 דקות).
```
חלק מההרשאות לא סומנו במסך של Google, ולכן לא אוכל לשלוח מיילים מ-Gmail.
אם זה היה בטעות — אפשר לאשר שוב כאן:
{link}
הקישור עובד ל-30 הדקות הקרובות.
```

### `g.mail.sent`
**מתי:** מייל שאושר בכפתור נשלח דרך Gmail.
**משתנים:** `{to_name}`, `{account_email}`
```
נשלח אל {to_name} מתיבת ה-Gmail ({account_email}).
```

### `g.cal.moved_all_day`
**מתי:** הזזה מאושרת של אירוע של יום שלם ביומן Google (אין שעה להציג).
**משתנים:** `{title}`, `{new_date}`
```
הוזז. {title} עכשיו ב-{new_date} (כל היום).
```

### `g.err.missing_scope`
**מתי:** Google החזירה 403 insufficientPermissions — ההרשאה לפעולה לא סומנה במסך האישור.
**משתנים:** היכולת החסרה, `{link}`
```
אין לי הרשאה לשלוח מיילים מ-Gmail בחשבון Google — כנראה שהאפשרות לא סומנה במסך האישור. אפשר להוסיף אותה כאן:
{link}
הקישור עובד ל-30 הדקות הקרובות.
```

### `g.err.gmail_read_unavailable`
**מתי:** בקשה לקרוא/לחפש/לסכם מיילים ב-Gmail (הכלי `gmail_read_status` מחזיר את הטקסט למודל).
**משתנים:** —
```
קריאה וסיכום של מיילים ב-Gmail עדיין לא זמינים — היכולת תתווסף אחרי בדיקת האבטחה של Google. שליחת מיילים מ-Gmail, היומן וקבצי Drive כבר עובדים.
```

### `g.err.attachment_too_large`
**מתי:** קובץ מ-Drive גדול מ-18MB לצירוף ל-Gmail.
**משתנים:** —
```
הקובץ גדול מדי לצירוף למייל (עד 18MB). אפשר לשלוח במקום קישור לקובץ ב-Drive.
```

### `g.err.event_gone`
**מתי:** הזזה/ביטול אושרו, אבל האירוע כבר לא קיים (404/410).
**משתנים:** —
```
הפגישה הזו כבר לא נמצאת ביומן — ייתכן שנמחקה או הוזזה. אפשר לבקש ממני להציג את היומן מחדש.
```

## 2. אתר (הודעות ב-`?notice=` / `?error=` אחרי חזרה מ-Google)

ההפניה: `returnTo=onboarding` → הצלחה ל-`/start/ready?connected=google`, כישלון ל-`/start/connect`; אחרת `/account`.

### `g.web.connected`
**משתנים:** `{account_email}`
```
החיבור ל-Google הושלם ({account_email}).
```

### `g.web.connected_partial`
**משתנים:** `{account_email}`, יכולות חסרות
```
החיבור ל-Google הושלם ({account_email}), אבל לא ניתנה הרשאה לשלוח מיילים מ-Gmail. אפשר לחבר שוב ולסמן את כל האפשרויות.
```

### `g.web.denied`
**מתי:** `error=access_denied` — המשתמש לחץ "ביטול" במסך של Google.
```
החיבור ל-Google בוטל במסך האישור. אפשר לנסות שוב בכל רגע.
```

### `g.web.admin_blocked`
**מתי:** `admin_policy_enforced` / `org_internal` — מנהל Google Workspace חוסם אפליקציות חיצוניות.
```
מנהל חשבון ה-Google Workspace של הארגון חוסם חיבור של אפליקציות חיצוניות. כדי לאפשר, מנהל המערכת מאשר את האפליקציה ב-Admin console (Security → API controls → App access control).
```

### `g.web.state_unknown`
**מתי:** state לא נמצא, כבר נוצל, או ישן מ-30 דקות.
```
החיבור לא הושלם: הבקשה לא זוהתה (אולי הקישור פג). אפשר להתחיל שוב.
```

### `g.web.failed`
**משתנים:** `{code}` (קוד השגיאה של Google)
```
החיבור ל-Google לא הושלם ({code}). אפשר לנסות שוב.
```

### `g.web.no_email`
```
החיבור ל-Google לא הושלם: Google לא החזירה כתובת מייל לחשבון. אפשר לנסות שוב ולאשר את שיתוף כתובת המייל.
```

### `g.web.link_expired`
**מתי:** קישור חיבור מהשיחה (`?t=`) פג או לא תקין — טקסט פשוט (410).
```
הקישור לא בתוקף (הוא עובד 30 דקות). אפשר לבקש קישור חדש בשיחה.
```

### `g.web.feature_disabled`
**מתי:** `?feature=gmail_read` כש-`GOOGLE_GMAIL_READ_ENABLED=false` — טקסט פשוט (403).
```
קריאת Gmail עדיין לא זמינה: היא דורשת בדיקת אבטחה של Google (CASA) שטרם הושלמה.
```
