## שיטה והנחות

- כל הודעה נשלחה לכל מודל עם אותו system prompt (עברית, כלים מדומים מול context.json), עד 4 סבבי כלים, concurrency 4, timeout 90s, עד 3 ניסיונות חוזרים.
