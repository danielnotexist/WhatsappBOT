# עלזה — טקסטים של חיבור Google (אבן דרך 6, שלב 1)

> מסמך מקור למחרוזות שמופיעות רק בזרימת Google. הקוד: `lib/copy/bot-google.ts` (בדיקה מוודאת שכל id מתועד כאן).
> מחרוזות משותפות לשני הספקים נשארות ב-`bot-copy.md` ומקבלות את הספק כמשתנה: `onb.connect_link`, `err.connection_expired`, `err.provider_down`, `err.not_connected`, `act.cal.*`.
> כללי סגנון: `style-guide.md` — פנייה ניטרלית למשתמש, בלי "שלח/י", בלי בדיחות; עלזה מדברת על עצמה בלשון נקבה.
> **קריאת Gmail (21.10.2026):** `gmail.readonly` הוא scope מוגבל. בלי CASA הוא נפתח רק למשתמשים הראשונים של האפליקציה הלא מאומתת (תקרת 100 של Google, אצלנו 95 — `lib/google/user-cap.ts`). מי שאין לו את ההרשאה מקבל את `g.gmail_read.consent` (קישור) או, כשהתקרה מלאה, את `g.err.gmail_read_cap_reached` (שורה אחת). טקסט שמבטיח "אעדכן כשתגיע תשובה" עדיין לא מתאים ל-Gmail (אין התראות על מיילים חדשים), ולכן יש `g.mail.sent` נפרד.

## 1. וואטסאפ

### `g.connect_done`
**מתי:** אחרי callback מוצלח של Google, אם יש מספר וואטסאפ מקושר. רשימת היכולות נבנית לפי ההרשאות שאושרו בפועל (granular consent).
**משתנים:** `{account_email}`, רשימת יכולות; האם קריאת Gmail התבקשה ולא סומנה.
```
החיבור ל-Google הושלם ({account_email}).
מעכשיו אפשר לבקש ממני:
• יומן Google — הצגה, קביעה, הזזה וביטול של פגישות
• קבצים ב-Drive שנוצרו או נפתחו דרכי
• שליחת מיילים מ-Gmail, אחרי אישור בכפתור
את תיבת ה-Gmail עצמה אני לא קוראת בשלב זה.
```
כשאושרה גם קריאת Gmail — נוסף הבולט "• קריאה, חיפוש וסיכום של מיילים ב-Gmail" והשורה האחרונה יורדת.
כשקריאת Gmail התבקשה בחיבור והסימון הוסר (לא תקלה — בחירה), השורה האחרונה היא:
```
את תיבת ה-Gmail אני לא קוראת, כי ההרשאה לכך לא סומנה. אפשר לבקש ממני בהמשך לקרוא מיילים, ואשלח קישור לאישור.
```

### `g.unverified_heads_up`
**מתי:** שורה אחת אחרי כל קישור חיבור ל-Google בשיחה (`onb.connect_link`, `err.connection_expired` — גם כשפעולה שאושרה בכפתור נכשלה כי החיבור פג, `g.err.missing_scope`, `g.connect_partial`, `g.gmail_read.consent`), כשהמסך של Google יציג "אפליקציה לא מאומתת": פרויקט Google אמיתי, וגם (ה-scopes הרגישים עוד לא אומתו או שהבקשה כוללת את `gmail.readonly`). הנוסח של דניאל, 21.10.2026.
**משתנים:** —
```
גוגל תציג מסך 'אפליקציה לא מאומתת' — זה צפוי בשלב הזה, אפשר ללחוץ 'מתקדם' ואז 'המשך'.
```
> במסך עצמו הקישור השני נקרא "מעבר אל עלזה (לא בטוח)" / "Go to Alze (unsafe)" — "המשך" בשורה הוא קיצור מכוון.

### `g.gmail_read.consent`
**מתי:** משתמש Google בלי הרשאת קריאה מבקש לקרוא/לחפש/לסכם מיילים, ועדיין יש מקום מתחת לתקרה (או שהחשבון כבר נספר). הכלי `gmail_read_status` מחזיר את הטקסט, והמודל מעביר אותו כלשונו. הקישור מבקש רק את `gmail.readonly` (הסכמה מצטברת — היומן ו-Drive לא מאושרים מחדש). שורת המסך הלא מאומת — רק מול פרויקט Google אמיתי.
**משתנים:** `{link}` (חד-פעמי, 30 דקות)
```
כדי שאוכל לקרוא את תיבת ה-Gmail צריך אישור נוסף אחד מ-Google:
{link}
גוגל תציג מסך 'אפליקציה לא מאומתת' — זה צפוי בשלב הזה, אפשר ללחוץ 'מתקדם' ואז 'המשך'.
הקישור עובד ל-30 הדקות הקרובות.
```

### `g.gmail_read.consent_no_link`
**מתי:** כמו `g.gmail_read.consent`, כשאין לכלי בונה קישורים (גיבוי — לא אמור לקרות בייצור).
```
כדי שאוכל לקרוא את תיבת ה-Gmail צריך אישור נוסף מ-Google. אפשר לכתוב "לחבר את גוגל" ואשלח קישור.
```

### `g.err.gmail_read_cap_reached`
**מתי:** בקשה לקרוא את Gmail כשתקרת המשתמשים מלאה והחשבון לא נספר קודם. וגם אחרי `g.connect_done`, כשהמשתמש סימן קריאת Gmail אבל בחר במסך של Google חשבון אחר שלא נספר, והתקרה מלאה (ההרשאה לא נשמרת). שורה אחת. היומן/Drive/שליחה לא נפגעים, וסיכום הבוקר שלו בלי "מיילים שמחכים לתשובה" מ-Gmail. בלי הבטחה מתי זה ייפתח — זה עוד לא הוחלט.
```
קריאת מיילים ב-Gmail פתוחה כרגע רק למשתמשים הראשונים, והמקומות התמלאו. היומן, Drive ושליחת מיילים מ-Gmail ממשיכים לעבוד.
```

### `g.drive_read.consent`
**מתי:** משתמש Google בלי `drive.readonly` מבקש לחפש או לקרוא קבצים קיימים ב-Drive (Docs, Sheets, Slides שלא נוצרו דרך עלזה), ועדיין יש מקום מתחת לתקרה (או שהחשבון כבר נספר). הכלי `gdrive_read_status` מחזיר את הטקסט, והמודל מעביר אותו כלשונו. הקישור מבקש רק את `drive.readonly` (הסכמה מצטברת). `drive.readonly` הוא scope מוגבל כמו `gmail.readonly`: אותה תקרה, מתג משלו (`GOOGLE_DRIVE_READ_ENABLED`).
**משתנים:** `{link}` (חד-פעמי, 30 דקות)
```
כדי שאוכל לחפש ולקרוא את כל הקבצים ב-Drive (כולל Docs, Sheets ו-Slides) צריך אישור נוסף אחד מ-Google:
{link}
גוגל תציג מסך 'אפליקציה לא מאומתת' — זה צפוי בשלב הזה, אפשר ללחוץ 'מתקדם' ואז 'המשך'.
הקישור עובד ל-30 הדקות הקרובות.
```

### `g.drive_read.consent_no_link`
**מתי:** כמו `g.drive_read.consent`, כשאין לכלי בונה קישורים (גיבוי).
```
כדי שאוכל לקרוא את כל הקבצים ב-Drive צריך אישור נוסף מ-Google. אפשר לכתוב "לחבר את גוגל" ואשלח קישור.
```

### `g.err.drive_read_cap_reached`
**מתי:** בקשה לקרוא קבצים קיימים ב-Drive כשתקרת המשתמשים מלאה והחשבון לא נספר קודם. וגם אחרי `g.connect_done`, כשסומנה קריאת Drive בחשבון אחר שלא נספר והתקרה מלאה (ההרשאה לא נשמרת).
```
קריאה של כל הקבצים ב-Drive פתוחה כרגע רק למשתמשים הראשונים, והמקומות התמלאו. קבצים שנוצרו דרכי, היומן ו-Gmail ממשיכים לעבוד.
```

### `g.err.drive_read_unavailable`
**מתי:** קריאת Drive כבויה (`GOOGLE_DRIVE_READ_ENABLED=false`, גם למי שכבר אישר) או שבדיקת התקרה נכשלה.
```
קריאה של כל הקבצים ב-Drive אינה זמינה כרגע. קבצים שנוצרו דרכי, היומן ו-Gmail ממשיכים לעבוד.
```

### `g.tasks.consent`
**מתי:** חיבור Google בלי `tasks` (חובר לפני 23.10.2026, או שהסימון הוסר) ומבקשים להציג או להוסיף משימה. הכלים `gtasks_*` מחזירים את הטקסט. הקישור מבקש רק את `tasks` (הסכמה מצטברת). `tasks` הוא scope רגיש, לא מוגבל — אין צורך ב-CASA.
**משתנים:** `{link}` (חד-פעמי, 30 דקות)
```
כדי שאוכל לעבוד עם Google Tasks צריך אישור נוסף אחד מ-Google:
{link}
הקישור עובד ל-30 הדקות הקרובות.
```

### `g.tasks.consent_no_link`
```
כדי שאוכל לעבוד עם Google Tasks צריך אישור נוסף מ-Google. אפשר לכתוב "לחבר את גוגל" ואשלח קישור.
```

### `g.tasks.created`
**מתי:** `gtasks_create_task` הוסיף משימה לרשימה הראשית (פעולה פנימית כמו תזכורת, בלי כפתור אישור). המודל עונה בנוסח הזה.
**משתנים:** `{title}`, שם השירות, תאריך יעד (24.10) אם יש

```
נוספה משימה ל-Google Tasks: להחזיר לעו"ד כהן את ההסכם, עד 24.10.
```

### `g.connect_partial`
**מתי:** מיד אחרי `g.connect_done`, כשהמשתמש הוריד סימון מאחת ההרשאות במסך של Google.
**משתנים:** רשימת יכולות חסרות, `{link}` (קישור חד-פעמי ל-30 דקות).
```
חלק מההרשאות לא סומנו במסך של Google, ולכן לא אוכל לשלוח מיילים מ-Gmail.
אם זה היה בטעות — אפשר לאשר שוב כאן:
{link}
הקישור עובד ל-30 הדקות הקרובות.
```

### `g.mail.sent`
**מתי:** מייל שאושר בכפתור נשלח דרך Gmail.
**משתנים:** `{to_name}`, `{account_email}`
```
נשלח אל {to_name} מתיבת ה-Gmail ({account_email}).
```

### `g.cal.moved_all_day`
**מתי:** הזזה מאושרת של אירוע של יום שלם ביומן Google (אין שעה להציג).
**משתנים:** `{title}`, `{new_date}`
```
הוזז. {title} עכשיו ב-{new_date} (כל היום).
```

### `g.err.missing_scope`
**מתי:** Google החזירה 403 insufficientPermissions — ההרשאה לפעולה לא סומנה במסך האישור.
**משתנים:** היכולת החסרה, `{link}`
```
אין לי הרשאה לשלוח מיילים מ-Gmail בחשבון Google — כנראה שהאפשרות לא סומנה במסך האישור. אפשר להוסיף אותה כאן:
{link}
הקישור עובד ל-30 הדקות הקרובות.
```

### `g.err.gmail_read_unavailable`
**מתי:** בקשה לקרוא/לחפש/לסכם מיילים ב-Gmail כשהיכולת כבויה (`GOOGLE_GMAIL_READ_ENABLED=false` — גם למי שכבר אישר) או שבדיקת התקרה נכשלה (הכלי `gmail_read_status` מחזיר את הטקסט למודל). וגם אחרי `g.connect_done`, כשהמשתמש סימן קריאת Gmail אבל היכולת כבתה בינתיים (ההרשאה לא נשמרת).
**משתנים:** —
```
קריאה וסיכום של מיילים ב-Gmail אינם זמינים כרגע. שליחת מיילים מ-Gmail, היומן וקבצי Drive עובדים.
```

### `g.err.attachment_too_large`
**מתי:** קובץ מ-Drive גדול מ-18MB לצירוף ל-Gmail.
**משתנים:** —
```
הקובץ גדול מדי לצירוף למייל (עד 18MB). אפשר לשלוח במקום קישור לקובץ ב-Drive.
```

### `g.err.event_gone`
**מתי:** הזזה/ביטול אושרו, אבל האירוע כבר לא קיים (404/410).
**משתנים:** —
```
הפגישה הזו כבר לא נמצאת ביומן — ייתכן שנמחקה או הוזזה. אפשר לבקש ממני להציג את היומן מחדש.
```

## 2. אתר (הודעות ב-`?notice=` / `?error=` אחרי חזרה מ-Google)

ההפניה: `returnTo=onboarding` → הצלחה ל-`/start/ready?connected=google`, כישלון ל-`/start/connect`; אחרת `/account`.

### `g.web.connected`
**משתנים:** `{account_email}`
```
החיבור ל-Google הושלם ({account_email}).
```

### `g.web.connected_partial`
**משתנים:** `{account_email}`, יכולות חסרות
```
החיבור ל-Google הושלם ({account_email}), אבל לא ניתנה הרשאה לשלוח מיילים מ-Gmail. אפשר לחבר שוב ולסמן את כל האפשרויות.
```

### `g.web.denied`
**מתי:** `error=access_denied` — המשתמש לחץ "ביטול" במסך של Google.
```
החיבור ל-Google בוטל במסך האישור. אפשר לנסות שוב בכל רגע.
```

### `g.web.admin_blocked`
**מתי:** `admin_policy_enforced` / `org_internal` — מנהל Google Workspace חוסם אפליקציות חיצוניות.
```
מנהל חשבון ה-Google Workspace של הארגון חוסם חיבור של אפליקציות חיצוניות. כדי לאפשר, מנהל המערכת מאשר את האפליקציה ב-Admin console (Security → API controls → App access control).
```

### `g.web.state_unknown`
**מתי:** state לא נמצא, כבר נוצל, או ישן מ-30 דקות.
```
החיבור לא הושלם: הבקשה לא זוהתה (אולי הקישור פג). אפשר להתחיל שוב.
```

### `g.web.failed`
**משתנים:** `{code}` (קוד השגיאה של Google)
```
החיבור ל-Google לא הושלם ({code}). אפשר לנסות שוב.
```

### `g.web.no_email`
```
החיבור ל-Google לא הושלם: Google לא החזירה כתובת מייל לחשבון. אפשר לנסות שוב ולאשר את שיתוף כתובת המייל.
```

### `g.web.link_expired`
**מתי:** קישור חיבור מהשיחה (`?t=`) פג או לא תקין — טקסט פשוט (410).
```
הקישור לא בתוקף (הוא עובד 30 דקות). אפשר לבקש קישור חדש בשיחה.
```

### `g.web.feature_disabled`
**מתי:** `?feature=gmail_read` כש-`GOOGLE_GMAIL_READ_ENABLED=false` (או שבדיקת התקרה נכשלה) — טקסט פשוט (403). וגם כהודעת שגיאה בחזרה מ-Google, כשההרשאה ניתנה אבל היכולת כבתה בינתיים.
```
קריאת Gmail אינה זמינה כרגע. היומן, Drive ושליחת מיילים מ-Gmail ממשיכים לעבוד.
```

### `g.web.gmail_read_cap_reached`
**מתי:** `?feature=gmail_read` כשתקרת המשתמשים מלאה והחשבון לא נספר קודם — טקסט פשוט (403). וגם כהודעת שגיאה בחזרה מ-Google, כשנבחר שם חשבון אחר שלא נספר והתקרה מלאה.
```
קריאת Gmail פתוחה כרגע רק למשתמשים הראשונים, והמקומות התמלאו. היומן, Drive ושליחת מיילים מ-Gmail ממשיכים לעבוד.
```

### `g.web.drive_read_disabled`
**מתי:** `?feature=drive_read` כש-`GOOGLE_DRIVE_READ_ENABLED=false` (או שבדיקת התקרה נכשלה) — טקסט פשוט (403). וגם כהודעת שגיאה בחזרה מ-Google, כשההרשאה ניתנה אבל היכולת כבתה בינתיים. שם המוצר מ-`BRAND.name`.
```
קריאה של כל הקבצים ב-Drive אינה זמינה כרגע. היומן, Gmail וקבצים שנוצרו דרך עלזה ממשיכים לעבוד.
```

### `g.web.drive_read_cap_reached`
**מתי:** `?feature=drive_read` כשתקרת המשתמשים מלאה והחשבון לא נספר קודם — טקסט פשוט (403), או בחזרה מ-Google כשנבחר חשבון אחר שלא נספר.
```
קריאה של כל הקבצים ב-Drive פתוחה כרגע רק למשתמשים הראשונים, והמקומות התמלאו. היומן, Gmail וקבצים שנוצרו דרך עלזה ממשיכים לעבוד.
```
