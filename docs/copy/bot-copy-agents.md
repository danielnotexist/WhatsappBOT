# טקסטים — סוכנים (מובנים ומותאמים)

> משלים את `bot-copy.md` (אותן מוסכמות: ניסוח ניטרלי, בלי "שלח/י", עלזה מדברת על עצמה בלשון נקבה, שם המוצר מ-`lib/brand.ts`).
> מקור האמת לכל id ב-`lib/copy/bot-agents.ts` (בדיקה: `lib/copy/bot-agents.test.ts`). תכנון: `docs/design/agents.md` §9–§11.
> על סוכן מדברים תמיד בצורה **"הסוכן ״<שם>״"** — דקדוק עקבי בלי קשר למגדר של השם. קישור התשלום תמיד מ-`payLinkFor(appUrl, user.id)`.
> "סוכן" — רק לפיצ'ר הזה (תפקיד בשם שהמשתמש קורא לו). עלזה עצמה היא תמיד "העוזרת".

## 1. מסלול ומצב

### `agent.limit.trial`
**מתי:** "סוכן חדש" בתקופת הניסיון. לא נוצרת שורה.
**משתנים:** `{payLink}`
```
סוכן משלך נפתח עם מנוי: במסלול הבסיסי סוכן אחד, ובמסלול פרו עד שלושה.
בינתיים אפשר לנסות את הסוכנים המובנים — למשל ״@מזכירה מה יש לי מחר?״.
להפעלת מנוי:
{payLink}
```

### `agent.limit.basic`
**מתי:** "סוכן חדש" במסלול הבסיסי כשכבר יש סוכן משלך.
**משתנים:** `{name}` (הסוכן הקיים), `{payLink}`
```
במסלול הבסיסי אפשר סוכן אחד משלך, והוא כבר קיים: ״{name}״. אפשר לערוך אותו (״עריכת סוכן {name}״), או למחוק וליצור חדש.
במסלול פרו — עד שלושה סוכנים משלך ושלושת הסוכנים המובנים:
{payLink}
```

### `agent.limit.pro`
**מתי:** "סוכן חדש" בפרו כשיש כבר שלושה.
```
יש כבר שלושה סוכנים משלך — המקסימום במסלול פרו. כדי ליצור סוכן חדש אפשר למחוק אחד מהקיימים (״סוכנים״ מציג את הרשימה).
```

### `agent.builtin_needs_pro`
**מתי:** פנייה לסוכן מובנה (או ניסיון לערוך/להשבית אותו) במסלול הבסיסי.
**משתנים:** `{name}`, `{payLink}`
```
״{name}״ הוא סוכן מובנה של מסלול פרו. במסלול הבסיסי אפשר ליצור סוכן אחד משלך, גם על בסיס התבנית של ״{name}״ — לכתוב ״סוכן חדש״.
למעבר לפרו:
{payLink}
```

### `agent.locked`
**מתי:** פנייה לסוכן מותאם שמעבר למכסת המסלול (אחרי הורדה מפרו).
**משתנים:** `{name}`, `{payLink}`
```
הסוכן ״{name}״ נעול: הוא מעבר למכסת הסוכנים של המסלול הנוכחי. אפשר למחוק סוכן אחר כדי לפנות מקום, או לעבור לפרו:
{payLink}
```

### `agent.trial_builtin_edit`
**מתי:** עריכה/השבתה של סוכן מובנה בתקופת הניסיון.
**משתנים:** `{payLink}`
```
בתקופת הניסיון אפשר לנסות את הסוכנים המובנים כמו שהם. התאמה אישית נפתחת במסלול פרו:
{payLink}
```

### `agent.not_found`
**מתי:** "@שם" / "סוכן: שם" / פקודת ניהול עם שם שלא קיים. לא נספר.
**משתנים:** `{name}`, `{names}` (הסוכנים הזמינים)
```
לא מצאתי סוכן בשם ״{name}״. הסוכנים שלך: ״מזכירה״, ״מתמחה״.
```
בלי סוכנים:
```
לא מצאתי סוכן בשם ״{name}״. עדיין אין סוכנים — ״סוכן חדש״ יוצר אחד.
```

### `agent.disabled`
**מתי:** פנייה לסוכן מושבת.
```
הסוכן ״{name}״ מושבת כרגע. להפעלה: ״הפעלת סוכן {name}״.
```

### `agent.created`
**מתי:** סוכן חדש נשמר.
```
הסוכן ״{name}״ מוכן. כדי לפנות אליו: ״@{name}״ בתחילת ההודעה — למשל ״@{name} מה חדש במייל?״.
כל מה שיוצא החוצה מגיע קודם לאישור בכפתור.
```

### `agent.approval_note`
**מתי:** אחרי שמירה, כשההנחיות כוללות ביטויים כמו "בלי אישור", "בלי לשאול", "שלחי ישר" (UX בלבד — ההגנה מבנית).
```
שימו לב: חלק מההנחיות מבקש לפעול בלי אישור. זה לא אפשרי — כל פעולה יוצאת עוברת אישור בכפתור, גם אצל סוכנים. שאר ההנחיות נשמרו.
```

### `agent.reply_header`
**מתי:** השורה הראשונה בכל בועה של סוכן, כולל טיוטות לאישור.
```
*{name}:*
```

### `agent.hello`
**מתי:** "@מזכירה" בלי בקשה. בלי מודל, לא נספר; הסוכן נשאר "דביק" ל-10 דקות.
**משתנים:** `{name}`, `{capsLine}` ("קריאת יומן, שינויים ביומן ותזכורות")
```
*{name}:*
כאן. במה לעזור? בתפקיד הזה אני מטפלת ב{capsLine}.
```

### `agent.back_to_main`
**מתי:** "@עלזה" / "עלזה," / "סיום" בלי בקשה — חזרה לעוזרת הראשית וניקוי הדביקות.
```
כאן {PRODUCT_NAME}. במה לעזור?
```

### `agent.list`
**מתי:** "סוכנים", "הסוכנים שלי", "מה הסוכנים יודעים לעשות?".
**משתנים:** שורה לכל סוכן, `{quotaLine}` (אחת משלוש השורות למטה)
```
*הסוכנים שלך*

• @מזכירה — קריאת מייל, טיוטות מייל, קריאת יומן, שינויים ביומן, תזכורות וסיכום בוקר
• @חשבוניות — קריאת מייל והעברת מיילים (מושבת)

{quotaLine}

לפנות לסוכן: ״@שם״ בתחילת ההודעה. ליצירה: ״סוכן חדש״. לעריכה: ״עריכת סוכן <שם>״.
```
סימונים: "(מושבת)", "(נעול)", "(במסלול פרו)".

### `agent.quota.trial`
```
בתקופת הניסיון אפשר לנסות את שלושת הסוכנים המובנים. סוכן משלך נפתח עם מנוי.
```

### `agent.quota.basic`
```
סוכנים משלך: {used} מתוך 1. הסוכנים המובנים כלולים במסלול פרו.
```

### `agent.quota.pro`
```
סוכנים משלך: {used} מתוך 3, בנוסף לשלושת הסוכנים המובנים.
```

## 2. יצירה (`profile.agent_draft`, פג אחרי 30 דקות)

> מתחיל גם מניסוח טבעי, כהודעה שלמה (בדיקה חיה של דניאל, 23.10.2026): "אתה יכול ליצור לי סוכן", "תיצרי לי סוכן", "אפשר ליצור סוכן?", "איך יוצרים סוכן?", "רוצה סוכן חדש" (`NEW_NATURAL_RE` ב-`lib/agents/commands.ts`). כל ניסוח אחר — העוזרת קוראת לכלי `start_agent_creation`, וה-pipeline מתחיל אותו תהליך.

### `agent.new.ask_template`
**מתי:** "סוכן חדש" (כשיש מקום). רשימה: מזכירה · מתמחה · מנהלת חשבונות · סוכן ריק (`ag:tpl:*`).
```
סוכן חדש. מאיפה מתחילים — מתבנית מוכנה, או מסוכן ריק?
```

### `agent.new.ask_name`
**מתי:** אחרי בחירת תבנית (או "סוכן חדש מזכירה"). כפתור [ביטול].
```
על בסיס ״{templateName}״. איך לקרוא לסוכן? שם קצר, 2–24 תווים — למשל ״{templateName} אישית״.
```
בלי תבנית:
```
איך לקרוא לסוכן? שם קצר, 2–24 תווים — למשל ״חשבוניות״ או ״לקוחות״.
```

### `agent.new.name_invalid`
**מתי:** שם לא תקין / שמור / תפוס. `{reason}` — אחד מ: "השם צריך להיות באורך 2 עד 24 תווים." · "בשם אפשר להשתמש באותיות, בספרות, ברווח, במקף ובגרש." · "השם הזה שמור לסוכן מובנה או לפקודה. אפשר לבחור שם אחר." · "כבר יש סוכן בשם הזה. אפשר לבחור שם אחר."
```
{reason}
איך לקרוא לסוכן?
```

### `agent.new.ask_instructions_template`
**מתי:** אחרי השם, בסוכן מתבנית. כפתורים [בלי תוספות] [ביטול]. ההנחיות של התבנית מועתקות לסוכן; התשובה מתווספת אליהן.
```
ההנחיות של ״{templateName}״ כבר מוכנות. מה להוסיף? למשל סגנון, לקוחות חשובים או מה לא לעשות. אפשר גם בהקלטה.
```

### `agent.new.ask_instructions_blank`
**מתי:** אחרי השם, בסוכן ריק. כפתור [ביטול].
```
מה הסוכן עושה ואיך? כמה משפטים — תחום, סגנון, מה חשוב ומה לא לעשות. אפשר גם בהקלטה.
```

### `agent.new.instructions_invalid`
**מתי:** הנחיות ריקות (בסוכן ריק) או ארוכות מ-1,500 תווים יחד עם התבנית.
```
{reason}
מה הסוכן עושה ואיך?
```

### `agent.new.ask_tools`
**מתי:** סוכן מתבנית — היכולות של התבנית. כפתורים [מתאים] [לשנות] [ביטול].
```
הסוכן יוכל: {capsLine}.
מתאים, או לשנות?
```

### `agent.new.choose_tools`
**מתי:** "לשנות", או סוכן ריק. רשימה של עד 8 חבילות (`ag:tb:*`): מייל לקריאה · מייל וטיוטות · מייל והעברות · יומן ותזכורות · קבצים · קבצים ושמירת מסמכים · מייל, יומן ותזכורות · הכול.
```
מה הסוכן יוכל לעשות? שליטה מלאה ביכולות — באזור האישי באתר.
```

### `agent.new.ask_recipients`
**מתי:** רק כשנבחרה העברת מיילים. כפתורים [בלי הגבלה] [ביטול].
```
לאילו כתובות מותר לסוכן להכין העברות ומיילים? עד 5 כתובות, מופרדות בפסיק. בכל מקרה כל העברה מגיעה לאישור בכפתור.
```

### `agent.new.recipients_invalid`
```
{reason}
עד 5 כתובות, מופרדות בפסיק — או ״בלי הגבלה״.
```

### `agent.new.summary`
**מתי:** לפני שמירה. כפתורים [שמירה] [ביטול].
```
*סוכן חדש: {name}*
על בסיס: {templateName}
יכולות: {capsLine}
נמענים מותרים: {recipients}
תוספות להנחיות:
> {instructions}
לשמור?
```
בסוכן ריק: "סוכן משלך, בלי תבנית" ו-"הנחיות:". שורת נמענים רק כשיש. ההנחיות מקוצרות ל-300 תווים בתצוגה.

### `agent.new.cancelled`
```
בוטל. הסוכן לא נשמר.
```

### `agent.new.expired`
**מתי:** כפתור `ag:*` של זרימה שכבר לא פעילה (עברו 30 דקות, או הסוכן נמחק).
```
הבחירה הזו כבר לא פעילה (עברו יותר מ-30 דקות). אפשר להתחיל שוב — ״סוכן חדש״, או ״סוכנים״ לרשימה.
```

## 3. עריכה, הפעלה, מחיקה

### `agent.edit.menu`
**מתי:** "עריכת סוכן {name}". רשימה (`ag:ed:<field>:<key>`): שינוי הנחיות / הנחיות נוספות (מובנה) · שינוי יכולות · נמענים מותרים · השבתה/הפעלה · מחיקה (מותאם בלבד).
```
מה לשנות בסוכן ״{name}״?
```

### `agent.edit.ask_instructions`
מותאם:
```
מה ההנחיות החדשות לסוכן ״{name}״? הטקסט מחליף את ההנחיות הקודמות. אפשר גם בהקלטה.
```
מובנה (פרו):
```
מה להוסיף להנחיות של ״{name}״? הטקסט מחליף את ההוספות הקודמות; ההנחיות הבסיסיות של הסוכן נשארות. אפשר גם בהקלטה. כדי למחוק את ההוספות — ״ריק״.
```

### `agent.edit.ask_tools`
**מתי:** אחרי "שינוי יכולות" — רשימת החבילות (במובנה: רק צמצום מתוך יכולות התבנית).
```
מה הסוכן ״{name}״ יוכל לעשות?
```

### `agent.edit.ask_recipients`
```
לאילו כתובות מותר לסוכן ״{name}״ להכין מיילים, העברות והזמנות? עד 5 כתובות, מופרדות בפסיק — או ״בלי הגבלה״.
```

### `agent.edit.saved`
```
נשמר. השינויים בסוכן ״{name}״ בתוקף מההודעה הבאה.
```

### `agent.edit.enabled`
```
הסוכן ״{name}״ פעיל. כדי לפנות אליו: ״@{name}״.
```

### `agent.edit.disabled`
```
הסוכן ״{name}״ הושבת. להפעלה מחדש: ״הפעלת סוכן {name}״.
```

### `agent.edit.cancelled`
```
בוטל. לא שיניתי כלום.
```

### `agent.delete.confirm`
**מתי:** "מחיקת סוכן {name}" (מותאם). כפתורים [מחיקה] [השאר].
```
למחוק את הסוכן ״{name}״? ההנחיות שלו נמחקות; מה שכבר נעשה נשאר ביומן הפעולות.
```

### `agent.delete.done`
```
הסוכן ״{name}״ נמחק.
```

### `agent.delete.kept`
```
הסוכן נשאר. לא שיניתי כלום.
```

### `agent.delete.builtin`
```
סוכן מובנה אי אפשר למחוק. אפשר להשבית אותו: ״השבתת סוכן {name}״.
```

### `agent.error`
**מתי:** פעולת ניהול שנכשלה מסיבה אחרת. `{reason}` — ההודעה של שכבת השירות (`AGENT_FAIL_MESSAGES` ב-`lib/agents/service.ts`), למשל "צריך לבחור לפחות יכולת אחת."
```
{reason}
```

## 4. העברת מייל (`forward_mail`)

### `act.mail.forward_confirm`
**מתי:** טיוטת העברה (כלי `forward_email`, Microsoft 365). כפתורים [העבר] [ערוך] [בטל]. אצל סוכן — עם הכותרת `*{name}:*` מעל.
```
*העברת מייל*
אל: {to}
נושא: {subject}
מאת: {from}
קבצים: {attachments}

> {comment}

להעביר?
```
שורות "מאת", "קבצים" וההערה — רק כשיש. היעד ראשון: כרטיס עם כפתורים נחתך ב-1,024 תווים, והשדות שאחריו (נכתבו על ידי שולח המייל) מקוצרים לשורה אחת — נושא ומאת עד 160 תווים, שמות קבצים עד 60 כל אחד ועד 240 ביחד ("ועוד N" לשאר), הערה עד 300.

### `act.mail.forwarded`
```
הועבר אל {to}.
```
