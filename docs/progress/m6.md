# אבן דרך 6 — Google, שלב 1 (בלי CASA)

> 21.10.2026 · ענף `worktree-agent-a04e828c4cf8d895e` · הערות לשילוב ב-`docs/PROGRESS.md` (לא נגעתי בו).

## מה נבנה

- **OAuth 2.0 web-server flow** (`lib/google/oauth.ts`): code + PKCE S256, `access_type=offline`, `prompt=consent`, `include_granted_scopes=true`. Scopes: `openid email profile`, `calendar.events`, `drive.file`, `gmail.send`. נקודות הקצה והפרמטרים אומתו מול developers.google.com (OAuth web server / native-app PKCE, Calendar v3 events + freeBusy, Gmail users.messages.send + uploads, Drive v3 files/export/uploads, טבלאות סיווג ה-scopes).
- **הסכמה מצטברת**: `scopesForRequest("gmail_read" | "gmail_modify")` מבקש רק את ה-scope החדש; חסום מאחורי `GOOGLE_GMAIL_READ_ENABLED=false` (דורש CASA — `docs/google-setup.md` §6).
- **נתיבים**: `GET /api/auth/google/start` (`?t=` קישור חד-פעמי מהשיחה או session; `returnTo=onboarding|account`; `feature=`), `GET /api/auth/google/callback` (state חד-פעמי + TTL של 30 דק', granular consent → הודעת "חלקי" + קישור להוספה, `access_denied`, `admin_policy_enforced`, `invalid_grant`). הפניה: onboarding → `/start/ready?connected=google` (כישלון → `/start/connect?error=`), אחרת `/account`. רק נתיבים קבועים — אין open redirect.
- **אחסון טוקנים**: AES-256-GCM דרך `lib/crypto` עם AAD `${userId}:google`; רענון 5 דק' לפני תפוגה; שמירת ה-refresh token הקיים כש-Google לא מחזירה חדש; `invalid_grant` (כולל תפוגת 7 ימים במצב Testing) → `expired` + audit → הבוט שולח קישור חידוש.
- **לקוח fetch בלי SDK** (`lib/google/client.ts`): Calendar list/get/create/patch/delete (`sendUpdates`), Drive list/get/download/export/create (multipart, המרה ל-Docs)/update/delete, Gmail send (RFC 2822 + base64url; מעל 4MB → upload URI `message/rfc822`), userinfo. סיווג שגיאות: 401, scope חסר (`ACCESS_TOKEN_SCOPE_INSUFFICIENT`), rate limit/5xx, 404/410.
- **MIME** (`lib/google/mime.ts`): כותרות בעברית ב-RFC 2047 (מילים ≤75 תווים), גוף UTF-8 base64, קבצים מצורפים multipart/mixed עם `filename*` (RFC 2231). **הגנת header injection**: CR/LF מנוקים מכל כותרת, כתובות לא תקינות נדחות.
- **כלים למודל** (`lib/google/tools.ts`, לפי ה-scopes שאושרו בפועל): `gcal_list_events`, `gcal_free_slots` (מחושב מ-events.list — בלי scope נוסף), `gcal_create_event`/`gcal_update_event`/`gcal_delete_event` (pending), `gdrive_list_files`, `gdrive_get_file_text` (Docs/Sheets/Slides → export; PDF → unpdf; Word/Excel/PPT → העתק זמני מומר, export, מחיקה), `gdrive_save_doc`, `gmail_draft_email` (pending, צירוף קובץ מ-Drive; Docs → PDF), `gmail_read_status` (כדי שמשתמש Google בלבד לא יקבל "צריך לחבר" כשמבקש לקרוא Gmail).
- **ניתוב ביצוע** (`lib/google/dispatch.ts`): executor אחד לכל סוג פעולה → `payload.provider` אם תויג, אחרת Microsoft פעיל, אחרת Google. כך `draft_email`/`create_event` הבסיסיים עובדים גם למשתמש Google בלבד.
- **Revoke**: ניתוק מהאזור האישי ומחיקת חשבון → `oauth2.googleapis.com/revoke` עם ה-refresh token לפני מחיקת הטוקנים (best-effort, נרשם ב-audit).
- **Picker**: לא בנוי (צד לקוח). TODO מפורט ב-`lib/google/client.ts` וב-`docs/google-setup.md` §8.
- **מצב memory**: כל ה-hosts של Google מוגשים מ-`lib/google/__fixtures__/google-fixtures.ts`.

## באג קיים שתוקן בדרך
`/^(לחבר|חבר|...)\b.*(מייל|...)/` ב-`process-inbound.ts` — ב-JS `\b` עובד רק על ASCII, ולכן "לחבר את המייל" (הטקסט שהבוט עצמו מבקש לכתוב ב-`err.not_connected`) **לא** זוהה; רק "חבר שוב" עבד. עבר ל-`lib/bot/connect-intent.ts` עם lookahead, ומזהה גם Google ("לחבר את גוגל", "ג'ימייל", "דרייב").

## לשילוב עם הסוכנים האחרים
- **UI/הרשמה**: כפתור "חיבור Google" במסך `/start/connect` → `/api/auth/google/start?returnTo=onboarding`; באזור האישי → `/api/auth/google/start`. הצלחה מגיעה ל-`/start/ready?connected=google&notice=…`; כישלון ל-`/start/connect?error=…`. להציג את טקסט הגילוי מ-`docs/legal/oauth-consent-screen-he.md` §3 לפני ההפניה.
- **סיכום בוקר/תזכורות**: לאירועי היום של משתמש Google — `googleForUser(db, user)` ואז `google.listEvents({ timeMin, timeMax, timeZone })` (ראו `dayRange` ב-`lib/google/tools.ts`, `localToInstant` ב-`lib/google/time.ts`). כשל `invalid_grant` בזמן job → החיבור כבר מסומן `expired`; מחוץ לחלון 24 שעות צריך את תבנית `reconnect_needed`.
